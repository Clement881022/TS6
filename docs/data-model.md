# M0 資料結構草案

> 狀態：草案，供戰鬥模擬核心（純 C# 類別庫）使用。欄位為建議，實作時可調整。規則來源見 [combat.md](combat.md)。
> 原則：全部資料表驅動；顯示名稱與規則欄位分離；核心不依賴 Unity。

## 1. 武將 Hero（靜態資料）

| 欄位 | 說明 |
|---|---|
| id / name | 識別與顯示名稱 |
| faction | 魏 / 蜀 / 吳 / 群 |
| rarity | R / SR / UR |
| role | 坦克 / 戰士 / 法師 / 弓手 / 醫療 / 軍師 |
| baseStats | 血量、攻擊、防禦、閃避、速度、爆擊、爆傷（隨等級成長）；速度 = 移動按鈕的移動範圍（1–3，隨職業固定，不隨成長） |
| attackType | 近戰 / 遠程 |
| deck | 卡牌 id 列表（固定套牌） |
| passive | 被動 id |
| starUnlocks | 星級 → 卡牌強化版 / 新增效果 |

## 2. 卡牌 Card

| 欄位 | 說明 |
|---|---|
| id / name / ownerHeroId | |
| cost | 0–3，也可更高（大招） |
| keywords | 破釜 / 蓄勢 / 先登（flags） |
| targeting | 目標規則（例：同路最前排、後排、自身、全隊友） |
| shape | 範圍形狀：單體 / 橫排 / 縱列 / 十字 / 全體 |
| effects | 效果列表（見下） |
| upgraded | 強化版覆蓋欄位（由卡牌強化與突破決定） |

### 效果 Effect

類型：傷害、治療、護甲、施加狀態（含持續回合）、移動 / 擊退 / 拉扯 / 換位、抽牌、獲得費用、復活。
每個效果記錄：倍率（例：傷害 = 攻擊 × 倍率）、作用對象。

## 3. 敵人 Enemy

| 欄位 | 說明 |
|---|---|
| id / stats / attackType | 同武將，另有 AI 行為表 |
| intentTable | 意圖類型（攻擊 / 防禦 / 治療 / 增益 / 移動 / 召喚 / 蓄力）與出現規則 |
| behavior | 簡單 AI：打得到就攻擊，否則移動；被挑釁時強制攻擊挑釁者 |

## 4. 狀態 Status

護甲、火攻、瘟毒、昏亂、破甲、挑釁。欄位：層數、持續回合、疊加規則、結算時機。

## 5. 戰鬥狀態 BattleState

- 雙方棋盤（5 路 × 2 排，尺寸資料驅動）、每格一個單位
- 抽牌堆、手牌、棄牌堆、移除區
- 費用（上限 10）、回合數、勝負條件
- 敵方意圖（本回合顯示）
- 隨機種子（可重播，供伺服器驗證）

## 6. 核心介面（建議）

- `Battle.Start(setup, seed)`
- `Battle.PlayCard(cardInstance, ...)`：目標自動判定，無目標則回傳不可打出
- `Battle.EndTurn()`：棄牌 → 敵方依序行動 → 下回合抽牌
- 事件流（傷害、移動、狀態變化）供 Unity 表現層訂閱，核心不處理動畫

## 8. 資料編輯流程（已定）

目標：企劃好改好看、程式好讀、前後端共用同一份資料。

**採用 Unity ScriptableObject 編輯 + 一鍵匯出 JSON。**

- 企劃在 Unity 內直接編輯武將 / 卡牌 / 敵人，可在 Inspector 預覽。
- 選單一鍵匯出 JSON；.NET 伺服器與純 C# 戰鬥核心讀同一份 JSON，不需要 .dat 之類的額外轉檔。
- 戰鬥核心使用與 Unity 無關的資料類別（POCO），ScriptableObject 只是編輯層，匯出時轉成 POCO / JSON。

已知取捨與對策：
- 其他企劃需要會用 Unity → 用 Git 協作，並寫簡單的編輯器視窗降低上手門檻。
- 批量調數值痛苦 → 之後可補 CSV 匯入 / 匯出工具，專門處理數值表（如成長曲線、掉落表）。
- 自動戰鬥策略的實作位置（核心內）
