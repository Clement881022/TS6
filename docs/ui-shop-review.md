# 商店修改驗收，2026-10-10

依使用者四張批註圖及後續確認完成。使用者另明確授權 Codex 本次直接移除豪華通行證機制。

## 完成內容

- 四個分頁共用外框，分頁固定在商品捲動區上方；「儲值」改為「禮包」。
- 小月卡呈現元寶 300 ＋ 100 × 30、體力 60 × 30；大月卡呈現元寶 680 ＋ 200 × 30、體力 120 × 30。
- 商店獎勵圖示可點擊或以 Enter／空白鍵開啟詳情。詳情以大圖及效果數值呈現，品級用名稱與外框顏色表示；不重複商品數量、部位或裝備操作位置。
- 禮包、通行證及將魂商品使用對應裝備圖片；武器自選匣保留寶箱圖，其攻擊／智力效果分列對應職業圖示。
- 元寶六種商品維持三欄兩排，增加排間距與底部留白。
- 通行證改為橫向等級卡。免費及高級券圖固定於最左側，上下兩排各標示一次；每個等級不再重複免費／付費文字。進度區縮短說明文字，一鍵領取固定於右下角。
- 通行證與將魂卡片支援滑鼠拖曳、垂直／水平滾輪橫向捲動，以及捲軸把手拖曳。超過六個 UI 單位的位移視為拖曳，抑制隨後的點擊；下一次按下滑鼠恢復正常點擊。按鈕保留原操作，不作為拖曳起點。
- 將魂商品改為可橫向捲動的雙排小卡，加入武將肖像與物品圖片。將魂數量移入商店上方資源條，兌換費用改為將魂圖示與數量，移除原將魂橫長條。
- 將魂商店武將商品改名為「信物」，道具詳情同步顯示此名稱。
- 飾品拆成兩種獨立庫存、碎片與將魂商品：爆擊型限戰士／射手，閃避型限其他職業。詳情各只顯示單一效果及可用職業圖示，數值沿用原加成。
- 舊已配戴飾品依武將職業決定類型。舊庫存與碎片按總量平分，奇數多的一件歸爆擊型；月購紀錄亦轉換。通行證第 15 級給爆擊型、第 30 級給閃避型，首儲禮包舊通用飾品獎勵轉為爆擊型。
- 將玩家能自然理解、詳情不重複數量與品級用色的 UI 原則寫入 AGENTS.md 長期規則。
- 移除豪華通行證商品、額外十級、980 元寶贈送與模擬工具購買呼叫；只保留 ¥30 普通通行證。
- 舊豪華存檔保留已獲得的元寶、等級及領取紀錄，當季權益正規化為普通付費通行證。舊未付款豪華訂單無法再兌付。

## 素材來源

沿用專案既有 ChibiSkin／UiSkin 資源圖、ChibiSkin 武將肖像與 EquipmentArt 裝備圖。新增爆擊型 accessory_crit.svg／PNG 以既有 accessory.svg 為底材修改外形、赤玉色與金色徽記，並非全新裝備原畫。免費與高級券圖由內建 image_gen 製作，透明 PNG 與提示紀錄位於 Assets/Resources/ShopArt；不增加豪華付費商品。

## 功能驗證

- 核心 299 項、伺服器 32 項測試全部通過。新增飾品錯誤職業拒絕、舊庫存與月購紀錄轉換、指定類型分解、掉落與碎片合成、通行證與將魂商品拆分驗證。
- PlaySim 建置通過，零警告、零錯誤。
- Unity Windows 建置通過；1600 × 900 驗證輸出 31 張截圖。
- 自動驗證商店外框底部留白、分頁與商品區無重疊、元寶兩排間距、通行證橫向捲動、裝備圖示點擊開啟說明。
- 第二次回報後增加操作驗證，前次只指定捲動值的驗收不足以保證滑鼠可操作。這次驗證垂直滾輪作用在道具上、卡片拖曳、道具拖曳、放開後停止移動、拖曳後不誤開詳情、捲軸把手拖曳、後續正常點擊可開詳情、卡片未被垂直裁切、一鍵領取位於右下角、將魂資源條有圖、兌換費用有圖與信物命名。
- 驗證武器自選匣詳情含攻擊／智力 +11%，青玉環只含閃避率 +4%，赤玉虎符只含爆擊率 +7%；詳情有圖片且沒有多餘數量、部位或操作位置文字。金幣詳情標題為金幣，不含 ×5000。通行證免費／高級標示只有兩個，兩張券圖載入成功。
- 執行期與樣式錯誤為零；保留原有 HomeLayout 的 last-child 偽類警告。核心測試仍有原有 CampaignBalanceTests 的 xUnit1013 警告。
