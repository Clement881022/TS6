# 商店修改驗收，2026-10-10

依使用者四張批註圖及後續確認完成。使用者另明確授權 Codex 本次直接移除豪華通行證機制。

## 完成內容

- 四個分頁共用外框，分頁固定在商品捲動區上方；「儲值」改為「禮包」。
- 小月卡呈現元寶 300 ＋ 100 × 30、體力 60 × 30；大月卡呈現元寶 680 ＋ 200 × 30、體力 120 × 30。
- 商店獎勵圖示可點擊或以 Enter／空白鍵開啟名稱、數量與用途說明；裝備另外顯示實際加成及職業差異。
- 禮包、通行證及將魂商品的裝備使用武器、防具、飾品對應圖片，替換原先通用寶箱圖。
- 元寶六種商品維持三欄兩排，增加排間距與底部留白。
- 通行證改為橫向等級卡，每級上下排列免費與付費獎勵；進度區縮短說明文字，一鍵領取固定於右下角。
- 通行證與將魂卡片支援滑鼠拖曳、垂直／水平滾輪橫向捲動，以及捲軸把手拖曳。超過六個 UI 單位的位移視為拖曳，抑制隨後的點擊；下一次按下滑鼠恢復正常點擊。按鈕保留原操作，不作為拖曳起點。
- 將魂商品改為可橫向捲動的雙排小卡，加入武將肖像與物品圖片。將魂數量移入商店上方資源條，兌換費用改為將魂圖示與數量，移除原將魂橫長條。
- 將魂商店武將商品改名為「信物」，道具詳情同步顯示此名稱。
- 裝備詳情讀取現有 Equipment 加成：武器依職業提供攻擊或智力百分比；防具提供生命與防禦百分比；飾品依職業提供爆擊率或閃避率百分點，另顯示品質與替換規則。
- 移除豪華通行證商品、額外十級、980 元寶贈送與模擬工具購買呼叫；只保留 ¥30 普通通行證。
- 舊豪華存檔保留已獲得的元寶、等級及領取紀錄，當季權益正規化為普通付費通行證。舊未付款豪華訂單無法再兌付。

## 素材來源

沿用專案既有 ChibiSkin／UiSkin 資源圖、ChibiSkin 武將肖像與 EquipmentArt 裝備 PNG。這次新增的是 UI 版面、圖示接入及說明互動，沒有宣稱新製裝備原畫。

## 功能驗證

- 核心 294 項測試全部通過，含豪華商品拒絕、普通版無額外獎勵、舊權益保留。
- PlaySim 建置通過，零警告、零錯誤。
- Unity Windows 建置通過；1600 × 900 驗證輸出 29 張截圖。
- 自動驗證商店外框底部留白、分頁與商品區無重疊、元寶兩排間距、通行證橫向捲動、裝備圖示點擊開啟說明。
- 第二次回報後增加操作驗證，前次只指定捲動值的驗收不足以保證滑鼠可操作。這次驗證垂直滾輪作用在道具上、卡片拖曳、道具拖曳、放開後停止移動、拖曳後不誤開詳情、捲軸把手拖曳、後續正常點擊可開詳情、卡片未被垂直裁切、一鍵領取位於右下角、將魂資源條有圖、兌換費用有圖與信物命名。
- 驗證良品武器詳情含攻擊／智力 +11%，青玉環詳情含爆擊率 +7 個百分點／閃避率 +4 個百分點。
- 執行期與樣式錯誤為零；保留原有 HomeLayout 的 last-child 偽類警告。核心測試仍有原有 CampaignBalanceTests 的 xUnit1013 警告。
