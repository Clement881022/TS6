# Q 版策略國風重製

最新人物置中、招募姿態與戰鬥修正版見 [戰鬥與人物構圖驗收](ui-battle-review.md)，最新證據存於 `build/battle-final/`。主城調整背景見 [主城修正版紀錄](ui-home-review.md)。以下為 2026-10-08 的歷史紀錄。

## 唯一美術基準

使用者貼回的設計圖存於 `art-chibi/reference.png`。上一版寫實人物、寫實宮城與大片象牙面板已撤回，不能再作為品質基準。

- 角色：大頭、短身、約三頭身，表情鮮明的精緻 Q 版武將，誇張但可辨識的武器與服裝。
- 場景：明亮暖日光、青瓦紅柱、圓潤卡通城鎮、粉色花樹與金黃銀杏、模型般的材質。
- 介面：深青黑漆面、細金邊與漢代幾何角紋；象牙色主要用於文字，主要操作用暖金。
- 字型：內文使用固定字重中文字型，展示標題使用 Noto Serif TC 固定 700 字重，保留 OFL 授權。[官方字型來源](https://github.com/google/fonts/tree/main/ofl/notoseriftc)。
- 戰鬥：沿用下方可選取與懸停上抬的扇形手牌，卡面頭像、背景、棋盤與 HUD 一起統一畫風。

## 實作

新美術全部存入 `client/Assets/Resources/ChibiSkin/`，由內建 imagegen 生成，沒有使用 CLI/API fallback。完整提示詞與輸出對照記於 `art-chibi/prompts.json`。所有生成圖片先檢查比例、畫風與透明度，再接入真實 UI；圖片不烘焙遊戲數值或操作文字。

`HeroArt` 僅載入 Q 版人物，禁止回退至上一輪寫實圖。`Chibi.uss` 取代 `Strategy.uss`；主城專用 `Home.uss` 最後載入。主城採用精簡頂欄、成組導航與整合主線進度的出征操作台；養成頁把完整立繪和資訊面板分開，並以已有完整立繪的武將作為首次展示。

`tools/import-chibi-art.ps1` 依圖集規格切出單元、依每張立繪的實際頭部位置建立頭像視圖。裁切不改變原始美術，保留透明 alpha。UR 關羽／張飛沿用同人物造型，沒有宣稱額外專屬皮膚。

## 驗收

先驗證風格，再驗證功能：人物必須 Q 版、城景必須明亮卡通、介面必須黑金；不得只靠執行成功判定完成。

`tools/verify-strategy-ui.ps1 -ReviewName chibi-review` 在隔離副本打包並執行真實頁面與戰鬥流程。每次產生 23 張新截圖，檢查尺寸及 runtime log，證據留在 `build/chibi-review/<解析度>/`。自動操作包含完整十連、養成分頁、名冊末端、長名稱、任務、商店、編隊、預覽、選牌、出牌、勝利與戰後回城。這是遊戲內自動流程驗證與截圖目視檢查，沒有冒稱人工滑鼠逐項驗收。

2026-10-08 最終 Windows 執行版建置成功。三種解析度各產生 23 張新截圖，共 69 張；尺寸核對通過，runtime error 掃描皆為 0。已目視檢查各頁總覽，並放大檢查主城、招募／十連結果、完整立繪、裝備、素材副本、七日目標、商店、編隊與戰鬥選牌。

| 解析度 | 新截圖 | Runtime errors | 證據 |
| --- | ---: | ---: | --- |
| 1920×1080 | 23 | 0 | `../build/chibi-review/1920x1080/` |
| 1366×768 | 23 | 0 | `../build/chibi-review/1366x768/` |
| 1280×1024 | 23 | 0 | `../build/chibi-review/1280x1024/` |

- 風格：移除寫實人物與宮城載入；明亮 Q 版場景配黑金漆面，展示標題實際使用襯線字型。
- 人物：所有 29 名實際名冊武將均通過頭像與完整立繪載入斷言；共保存 33 張完整立繪，含尚未出現在名冊的既有角色。大幅立繪保持透明背景與完整武器。
- 排版：主城導航與章節牌不遮住中央地標；養成三欄、長名稱、列表末端及 5:4 戰場／手牌保持可讀。素材副本與裝備列表可捲動。
- 互動：下方手牌預覽、選取、目標提示、實際出牌、勝利與回城流程通過。招募主頁及結果頁均依元寶餘額停用抽卡按鈕；最終十連結果截圖已確認「再抽十連」停用。

本輪 2D UI 重製通過上述風格與流程檢查，可交付這份可執行版本供評審；這不代表 3D 模型、演出與測試付款流程已完成正式商用製作。舊寫實版本的品質結論保持撤回。

執行檔：`../build/strategy-win/SanGuo.exe`。截圖目錄內保留 `capture-manifest.json` 和 `player.log`；總覽為 `../build/chibi-review/contact-<解析度>.png`。

## 製作範圍

本輪重製 2D 美術與 UI。戰鬥及「切換模型」仍使用現有 Q 版 3D 角色模型與動畫；商店仍為測試付款流程。
