# 沉穩策略國風 UI

本檔記錄上一輪美術。該版已因偏離使用者選定的 Q 版設計而撤回，現行版本採 `ui-chibi.md` 與 `UI/Chibi.uss`。

2026-10-08：依使用者選定方向全面重畫介面美術，包含背景、面板、主按鈕、出征徽牌、導航與戰鬥圖示、武將立繪與頭像。

## 美術規格

- 目前展示版使用青綠頂欄 `#2B4141`、象牙資訊面板 `#EFEBDC`、暖銅金 `#CEAF67`；場景保留自然亮度，朱砂限於提示、軍旗與負面狀態。
- 以真正的 Unity UI Toolkit 元件承載文字、數值、分頁及操作。生成圖沒有烘焙遊戲數字或功能文案。
- `Strategy.uss` 最後載入；功能入口集中在主城左側，右上放主線進度，右下出征。
- 武將頁：左側可捲動名冊、中央立繪／模型展示、右側屬性與養成操作。顯示真實裝備分頁，不套用概念稿虛構的功能。
- 招募、地圖、副本、商店、任務、編隊、劇情對白、戰鬥 HUD 共用相同顏色及材質規格。UI 使用由原始中文字型生成的固定 500 字重，避免可變字型預設極細筆畫。
- 3D 戰鬥單位仍由專案的角色模型系統渲染；本次重畫的是介面用 2D 美術與背景。

## 驗證

戰鬥手牌改為下方扇形卡牌列，每張牌顯示真實費用、武將頭像與規則效果。滑鼠懸停與選牌會放大、上抬並顯示棋盤範圍；點選目標施放，無目標牌沿用詳情的使用按鈕。左侧保留可點選的隊伍生命資訊，右下為費用、結束回合及牌堆。卡牌間距依手牌數量與可用寬度調整。

`tools/verify-strategy-ui.ps1` 同步核心、複製到隔離建置副本、打包並執行真實操作／逐頁截圖。建置與截圖 log 留在 build 目錄。背景建置需要可連接 Unity Hub 授權服務的桌面權限；截圖預覽視窗不可最小化。

美術生成稿已接入遊戲；不以概念稿代替真實畫面驗證。資產清冊的上線核准狀態沿用專案流程。
