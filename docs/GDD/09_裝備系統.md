# 裝備系統

裝備為武將成長途徑之一（另有等級與突破）。1.0 保持精簡。

## 1. 規則

- 每名武將 3 個部位：武器、防具、飾品。
- 品階 1–5，每高一階，主屬性約 +10%（1 階 +10%，5 階 +50%，線性）。
- 屬性固定，無隨機詞條。
- 1.0 不做裝備強化，僅以品階提升；強化留待後續版本。
- 取得：素材副本。五階副本（體力 20／25／30／35／40）對應裝備品階 1–5，隨章節解鎖。
- 重複裝備可分解為金幣，金幣回流至武將升級與突破。若上線後數據顯示後期缺乏目標，再評估加入「重複裝備精煉」。

| 部位 | 主屬性方向 |
| --- | --- |
| 武器 | 攻擊或謀略（依職業） |
| 防具 | 生命、防禦 |
| 飾品 | 爆擊、閃避、移動力 |

## 2. 目標

一個月後主力平均配有 3–4 階裝備（見 `05_經濟與養成循環.md` §6）。

## 3. 戰力貢獻（試算）

- 以平均 3.5 階計，主屬性約 +35%。
- 4 名主力共 12 件，一個月內約可刷素材副本 140 次，足以湊齊。
- 與等級成長（+58.5%）、突破（主屬性 +20%）相比，裝備約占整體成長的三成，見 `03_武將系統.md` §4.2。

## 4. 待決事項

- 每件裝備的名稱與數量（每部位每品階的種類數）。
- 裝備是否綁定職業，或通用。
- 裝備可否在武將間轉換。
- 素材副本的掉落機率與每次產出數量。
