## 1. 文件定位

本文件體系為《三國將星傳》1.0 版本的遊戲設計依據，內容一經核定，即為專案的最高設計準則。實作或原型（Demo）與本文件不一致時，以本文件為準。

文件約定：

- 未特別標註的敘述為已核定規則。
- 標註「（草案）」者為暫定內容，尚待驗證或核定。
- 尚未決定的事項集中列於各文件末的「待決事項」，並彙整於 `99_待決議題.md`。
- 各職業的「長期定位」與「1.0 實作範圍」分開記載：長期定位為後續版本的營運方向，1.0 僅實作其中必要且簡單的子集。

## 4. 核心循環

主線循環：消耗體力挑戰主線關卡或素材副本，戰後取得金幣、裝備與元寶；透過抽卡取得新武將（重複武將用於突破）；以武將經驗與金幣升級、以重複武將與金幣突破並配戴裝備，提升戰力後挑戰門檻更高的關卡。

終局循環：以養成成果挑戰每月賽季的世界 Boss，依造成的傷害競爭排行榜；賽季獎勵（元寶、稱號）回流為抽卡資源。

## 5. 術語

| 術語 | 定義 |
| --- | --- |
| 費 | 每回合可用於出牌的資源 |
| 卡位 | 一張牌占用手牌與牌庫空間的成本，估值 0.5 費 |
| 效價 | 一張牌的效果總價值，等於出牌費用加卡位 |
| 佔模 | 效果形狀或類型對費用估值的倍率 |
| 移動牌 | 費用為 0、移動指定武將的通用牌 |
| 層 | 燃燒等持續傷害的強度單位 |
| 突破 | 消耗重複取得的武將與金幣，提升武將的 5 段成長 |
| 將魂 | 已滿突武將的溢出重複轉成的專屬兌換貨幣，於將魂商店使用 |
| 戰力 | 攻擊與生命的乘積，用於衡量關卡門檻 |
