# UI 與教學

> 本文件沿用既有原型的做法（見 `docs/chapter0.md`）。

## 1. 螢幕

- 橫式，參考解析度 1920×1080。
- 自動旋轉僅允許橫向。

## 2. 教學

- 由「巴豆妖」旁白，在戰鬥中以對話框說明出牌、費用、移動等系統機制。
- 教學章（第零章，共 10 關）依序引入機制，並於首通時贈送劉備、張飛、關羽。

原型的教學關內容：

| 關 | 教學機制 |
| --- | --- |
| 1 | 出牌、費用 |
| 2 | 嘲諷（張飛） |
| 3 | 破甲（關羽） |
| 4 | 優先擊殺治療者 |
| 5 | 蓄力大招、昏亂 |
| 6 | 護送、護甲 |
| 7 | 火攻 |
| 8 | 召喚、縱列穿透 |
| 9 | 綜合（開放編隊） |
| 10 | Boss：蓄力、大招、召喚 |

1.0 的戰鬥機制僅保留蓄力大招（嘲諷可打斷）。昏亂、召喚、縱列穿透、護甲與火攻引爆不納入 1.0，第 5、6、7、8、10 關的教學內容須依此重新設計。

教學關與各章 Boss 的細節於實作時再細化，本文件不預先規定。
