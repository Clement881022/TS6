# 待決議題

本文件彙整各文件的「待決事項」。事項定案後，應移入對應文件並自本清單刪除。

## 戰鬥系統（01）

- 閃避率上限。
- 破甲數值的計算方式（例如破甲 25% 是否等同防禦乘以 0.75）。
- 費用超過上限時的處理，以及移動牌是否計入每回合的抽牌數。
- 同一單位持有多個護盾時的消耗順序。
- 我方入場區的確切位置（位於哪兩列）。

## 卡牌系統（02）

- 戰士「爆擊強化」的具體形式（下一次攻擊必定爆擊，或爆擊率增益）與定價。
- SR／UR 卡牌升級的幅度。

## 武將系統（03、08）

- 各武將的主要與次要屬性（突破模板用）。
- 首批 SR 名單超出名額時的取捨，以及預備名單的上線順序。

## 關卡與敵人（04）

- 護送目標是否會自行移動、我方是否可控制。
- 「限時」目標與「守城」目標的差異（例如是否另有「撐過回合」的勝利型態）。
- 一關可否混合多個目標類型。
- 多格單位（Boss）的規則：被範圍攻擊命中的次數、距離與嘲諷的判定、占用格是否阻擋其他單位。
  - 草案：占用格皆阻擋；距離以最近一格計；範圍攻擊命中任一格即生效，且每次技能僅結算一次。
- 行動預告是否顯示傷害數值，以及預告的 UI 規格。
- 各章逐關配置、Boss 技能與階段設計、蓄力回合數（於實作時細化）。
- 首通獎勵與重複挑戰獎勵。
- 敵人等級曲線須以核心戰鬥模擬校準。

## 經濟與養成（05、09）

- 突破所需的金幣數量曲線。
- 將魂：各稀有度的轉換數量、商店商品清單、價格與每月限購次數；劇情固定武將的重複份是否可兌換。
- 升級所需的武將經驗與金幣曲線。
- 武將經驗在素材副本中的產出方式。
- 劇情武將重複份的贈送節奏與數量；其他客串武將（黃忠、龐統、趙雲等）是否贈送。
- 通行證與首儲禮包的內容與定價；通行證的階段數與大獎內容。
- 日常任務。
- 世界 Boss：挑戰次數與是否消耗體力、單次戰鬥的回合限制、排名採累計傷害或單次最高傷害、Boss 的輪替與機制、排名區間劃分與各區間獎勵。
- 三個付費層級（無課、小課、大課）的月度抽數與付費目標，需依營運目標校準。
- 裝備：名稱與數量、是否綁定職業、可否轉換、掉落機率與產出數量。

## 世界觀、美術與 UI（06、07）

- 幕後主使、魔化規則、主角能否回到現代、主角姓名。
- 場景美術風格、UI 皮膚與字型、音樂與音效方向。
- 手牌擺放、費用顯示、行動預告的 UI 規格；目標選擇與範圍預覽；主城與選單結構。
