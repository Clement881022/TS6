# 戰鬥系統

## 1. 戰場與回合

### 1.1 回合結構

戰鬥採雙方輪流的整回合制：我方完成全部行動後，換敵方行動。

### 1.2 戰場規則

- 戰場為 5×5 格。
- 我方於己方半場中央、橫 3 格 × 直 2 格的區域（共 6 格）入場，容納 4 名武將。敵方依關卡配置，可占用其餘 19 格。
- 一格僅能容納一個單位。單位不可重疊，亦不可穿越任何單位（友軍或敵人）。
- 距離以上下左右計算（曼哈頓距離），不含斜角。
- 範圍型技能（橫排、十字等）的中心點，由玩家在攻擊範圍內選擇。
- 1.0 無地形，亦無位移類效果（擊退、拉扯、交換）。日後擴充時，位移被邊界或單位阻擋則不移動。

### 1.3 出牌限制

每名武將、每張牌均無出牌次數限制，只要手牌與費用足夠即可出牌。

### 1.4 「全體」的定義

- 全體攻擊的目標為全場所有敵人，不受攻擊範圍限制，不需走位，此為設計意圖。
- 我方全體效果（治療、增益等）的目標為我方全部存活武將，最多 4 名。

### 1.5 設計意圖

- 費用與手牌可累積至上限（各 10），玩家可累積後單回合爆發，不另設累積代價。
- 坦克移動力低，從前排入場，需藉移動牌推進至前線。

## 2. 隊伍與牌庫

- 隊伍固定 4 名武將。
- 全隊共用一個牌庫，每張牌綁定其所屬武將。
- 開局時，每名武將額外將 1 張移動牌洗入牌庫。4 人隊的牌庫共 24 張（20 張專屬卡、4 張移動牌）。
- 武將陣亡時，其專屬卡與 1 張移動牌自牌庫、手牌與棄牌堆中移除。
- 戰鬥結束後全員完全恢復，陣亡不造成永久損失。

## 3. 費用與手牌

| 項目 | 規則 |
| --- | --- |
| 每回合費用 | 3 費 |
| 第 1 回合抽牌 | 隨機 5 張，另固定抽 2 張移動牌（共 7 張，約占牌庫三成） |
| 之後每回合抽牌 | 3 張 |
| 保留 | 未用費用與手牌保留至下回合 |
| 上限 | 費用 10、手牌 10 |
| 用過的牌 | 進入棄牌堆 |
| 牌庫抽完 | 棄牌堆洗回牌庫 |
| 手牌已滿 | 超出上限的抽牌直接棄置 |

## 4. 傷害與減免

傷害採乘法減傷模型，防禦值愈高，物理傷害承受比例愈低。

| 項目 | 規則 |
| --- | --- |
| 物理傷害 | 攻擊 × 技能倍率 × 100 ÷ (100 + 防禦) |
| 法術傷害 | 謀略 × 技能倍率，不受防禦影響 |
| 爆擊 | 僅物理傷害可爆擊，法術傷害不爆擊 |
| 爆擊傷害 | 基礎 150%，無上限 |
| 爆擊率 | 上限 100% |
| 閃避 | 物理與法術攻擊皆可閃避 |
| 破甲 | 降低目標的防禦比例，規則見 §5 |

## 5. 狀態效果

### 5.1 通則

- 所有增益與減益各自獨立存在，各自計算持續回合，可疊加。例如多張防禦增益可累加，防禦 +50 疊三次為 +150。
- 例外一：同名破甲不疊加，取最高值。各破甲仍各自計算持續回合。例：A「破甲 25%、2 回合」與 B「破甲 50%、1 回合」並存時，第 1 回合生效 50%，第 2 回合 B 結束，生效 25%。
- 例外二：嘲諷以後施加者覆蓋先前者，不疊加。

### 5.2 各狀態

| 狀態 | 規則 |
| --- | --- |
| 護盾 | 視為額外生命值，於生命值之前吸收傷害，物理與法術傷害一體適用。無持續時間，吸收完畢才消失。 |
| 燃燒 | 於被燃燒單位所屬陣營的回合結束時，造成等同於層數的傷害；結算後層數衰退 50%（向下取整）。施放時的層數等於施放者謀略乘以技能倍率。無層數上限。傷害為固定數值，可被護盾吸收。燃燒的佔模為 ×1.5。 |
| 嘲諷 | 使全場敵人以施放者為攻擊目標，遠程與範圍攻擊同樣適用。標竿持續 1 回合。敵人不可使用嘲諷。 |
| 其他增益與減益 | 以回合數計算持續時間。 |

燃燒範例：施放 8 層，各次回合結束依序受 8、4、2、1 點傷害，總計 15 點。

## 6. 敵人蓄力

1.0 的敵人特殊機制僅有「蓄力大招」。

- 蓄力回合數依敵人而異。
- 蓄力完成後，於該敵人下一次輪到行動時釋放。
- 目標於開始蓄力時鎖定，因此大招通常為全體技能，避免目標失效。
- 蓄力期間，行動預告僅顯示「蓄力中」，不顯示傷害與範圍。
- 嘲諷可打斷蓄力，被打斷後取消並重新開始蓄力。擊殺亦可終止蓄力。除此之外沒有其他效果可打斷。

## 7. 勝負條件

- 關卡目標類型：全滅、護送、守城、限時、擊殺指定目標，詳見 `04_關卡與敵人.md`。
- 失敗條件：我方全員陣亡，或任務目標失敗（例如護衛目標死亡、限時任務超過回合數）。

## 8. 待決事項

- 閃避率上限。
- 破甲數值的計算方式（例如破甲 25% 是否等同防禦乘以 0.75）。
- 費用超過上限時的處理，以及移動牌是否計入每回合的抽牌數。
- 同一單位持有多個護盾時的消耗順序。
- 我方入場區的確切位置（位於哪兩列）。
