# 世界觀與美術

> 本文件沿用既有原型的方向（見 `docs/worldbuilding.md`、`docs/art-pipeline.md`），並將採用的部分列為正式設計。兩者不一致時以本文件為準。

## 1. 世界觀

- 題材：三國。前期依《三國演義》，後期為架空。
- 主角：現代上班族穿越為涿縣同鄉的聰明少年，與劉備相熟，不具武力，憑藉頭腦與「命牌」指揮作戰。
- 命牌：主角醒來時握在手中的一疊發光牌，作為「玩家以出牌指揮」的世界觀解釋。
- 主角團：主角與劉備、關羽、張飛。其他英雄多為客串，戲份有意壓低。
- 章節方向：第零章涿縣盜匪（教學）→ 黃巾之亂 → 討董 → 架空章節（群雄被不明力量魔化）。
- 1.0 劇情範圍：第零章教學與 6 章主線，止於討董。官渡、赤壁與架空的魔化名將留待後續版本。

## 2. 敘事規則

- 劇情旁白為無名旁白；主角內心獨白以括號標示。
- 巴豆妖僅負責系統性戰鬥教學，不出現在劇情中。
- 每關設戰前與首通後劇情，可略過。
- 對白偏輕鬆，保留演義名場面作為彩蛋。

## 3. 美術方向

- 風格：Q 版，約 3 頭身，粗描邊，高飽和與高對比，金屬材質具高光。
- 戰鬥：3D 卡通渲染角色（描邊與階梯明暗）。
- 立繪與卡面：2D 手繪 Q 版插畫。
- 不得複製既有遊戲的角色設計。
- 原型階段的美術皆為占位，須登記於 `art/manifest.json`；正式版須由專業美術交件。

## 4. 待決事項

- UI 皮膚與字型（手機須內嵌中文字型）。
- 音樂與音效方向。
