# 卡牌系統

## 1. 卡牌組成

- 每名武將擁有 5 張專屬卡：3 張基本攻擊卡與 2 張職業特殊卡。
- 卡牌綁定所屬武將，出牌時由該武將執行。
- 移動牌為通用牌，費用 0，可指定任一武將移動，移動距離等於該武將的移動力。移動牌占用牌庫與手牌空間卻不產生輸出，此為設計意圖：移動需付出手牌空間作為代價。

## 2. 費用價值體系

以「各效果值多少費」作為卡牌平衡的基準，新增效果時依此補入。

**效價 = 出牌費用 + 0.5（卡位）**

| 效果 | 效價 |
| --- | --- |
| 抽 1 張牌 | +0.5 費 |
| 回復 1 點費用 | +1.0 費 |
| 棄 1 張牌 | −0.5 費 |
| 單體 1 倍傷害（1 費 1 卡） | 1.5 費 |
| 單體 1 倍治療（1 費 1 卡） | 1.5 費 |
| 護盾 | 佔模 ×1.5 |
| 燃燒 | 佔模 ×1.5 |
| 橫排或豎排 3 格範圍 | 佔模 ×1.5（例：倍率 80% = 1.5 × 0.8 ≈ 2.2 費） |
| 十字範圍 | 佔模 ×2 |
| 全體 | 佔模 ×3 |
| 破甲 25% | 約 0.25 費 |
| SR 特殊卡 | 每張佔模額外 +1 費 |
| UR 特殊卡 | 每張佔模額外 +2 費 |

說明：

- R 卡為基準，不加額外價值。
- SR／UR 的 +1／+2 為效價，不是出牌費用。範例（UR，虛構）：「虎嘯龍吟斬」3 費、單體、物攻 ×3.67，3.67 × 1.5 = 5.5 = 3 + 0.5 + 2。
- 群體治療與群體護盾，沿用攻擊的橫排、十字、全體佔模倍率。
- 回費與抽牌亦受效價限制。例：1 費「抽 3 張」= 3 × 0.5 = 1.5；1 費「棄 1 張牌並回 2 費」= 2 − 0.5 = 1.5。
- 「攻擊 +X%」僅提升物攻；同時提升謀略者須在卡面明確標示。

## 4. 標竿驗算

驗算依據：效價 = 費用 + 0.5。

| 卡 | 計算 | 效價 |
| --- | --- | --- |
| 基本攻擊 | 1.0 × 1.5 | 1.5（1 費） |
| 重斬 | 1.67 × 1.5 | 2.5（2 費） |
| 橫斬 | 1.11 × 1.5 × 1.5 | 2.5（2 費） |
| 治療 | 1.0 × 1.5 | 1.5（1 費） |
| 屏障 | 0.67 × 1.5 × 1.5 | 1.5（1 費） |
| 破甲箭 | 1.5 × 1.5 = 2.25，預算 2.5，餘 0.25 為破甲 25% | 2.5（2 費） |
| 火攻 | 1.67 × 1.5（燃燒佔模） | 2.5（2 費） |
| 嘲諷 | 預算 1.5，即全場敵人嘲諷 1 回合價值 1.5 費 | 1.5（1 費） |
| 群體鼓舞 | 預算 1.5，即全體物攻 +25% 持續 2 回合價值 1.5 費 | 1.5（1 費） |

上述效果價值為後續新卡設計的基準。

## 5. 卡牌升級

- 升級由突破帶來，逐張卡生效：一張卡升級為強化版後，同名的其餘複本不變。例（義勇盾兵）：二突將 1 張嘲諷升級為「嘲諷＋」，五突再將另 1 張升級為「嘲諷＋」。
- R 卡每次升級約提升 0.5 費效價（R 卡的突破取得容易，幅度較小）。SR／UR 的幅度另行制定。
- 非傷害卡的升級方式：治療與屏障提高倍率；嘲諷延長持續回合（嘲諷＋）；鼓舞提高強度或延長持續回合。

## 6. 職業卡牌方向（1.0）

各職業的長期定位見 `03_武將系統.md`。本節為 1.0 實際實作的卡牌方向，其餘留待後續版本。

### 6.1 坦克

- 方向：加防禦，另有嘲諷；工具卡費用相對低。
- 1.0 不做反擊與保護隊友（替隊友承傷）。
- 防禦增益採固定值，不採百分比：坦克承受敵方傷害，百分比增益會使數值膨脹過快。
- 基準：防禦 +50 約提升 25% 有效生命。

| 效果 | 效價 |
| --- | --- |
| 自身防禦 +50，持續 2 回合 | 1.0 費 |
| 單體友軍防禦 +50，持續 2 回合 | 1.5 費 |
| 全隊防禦 +50，持續 2 回合 | 3.0 費 |

範例：單體友軍「掩護」1 費，防禦 +50 持續 2 回合；自身「固守」1 費，防禦 +50 持續 3 回合。

### 6.2 戰士

- 方向：高倍率單體重擊、小範圍 AOE（橫排、十字等）、爆擊強化。
- 不以自身攻擊增益為主要方向。

### 6.3 遊俠

- 方向：單體高倍率狙擊、十字箭雨、自身閃避增益，另有單體破甲。
- 副輸出定位以武將數值平衡：攻擊射程長，但攻擊數值低於戰士，卡牌倍率不另調降。

### 6.4 術士

- 方向：單體高倍率法術、範圍法術傷害（橫排、十字、全體）、燃燒。
- 1.0 不做降攻、降謀略等屬性減益，亦不做中毒、流血等其他持續傷害。1.0 敵方減益僅有破甲、燃燒、嘲諷。

### 6.5 軍師

- 方向：我方增益（物攻、謀略）、回費、抽牌。
- 1.0 不做敵方屬性減益與位移。

### 6.6 醫者

- 方向：治療與護盾，各含單體與群體。
- 1.0 不做驅散，後續版本另設專門的驅散醫者。
