# 養成設計

> 狀態：草案（持續更新）。後續要擴展再擴展，初期只做最小集合。

## 1. 養成維度（初期）

| 維度 | 作用 | 消耗 |
|---|---|---|
| 武將等級 | 提升武將自身數值 | 待定（經驗類素材 / 金幣） |
| 卡牌強化 | 強化卡牌效果（傷害等） | 專用的「卡牌強化素材」（非金幣） |
| 突破（星級） | 屬性加成與特殊效果混搭（2★ / 5★ 為特殊效果） | 該武將的重複碎片（每星 20） |

戰鬥面的強化方向見 [combat.md](combat.md)。

## 2. 重複武將處理

- 抽到已擁有的武將 → 轉換為該武將的 **20 碎片**（一隻重複 = 一次突破），見 4.1。
- 多餘的突破素材 → 可分解成金幣。

## 3. 素材產出與體力

- 主要靠資源副本（30–60 秒、可掃蕩）。
- 體力制（暫定）：主線、資源副本、高難關卡**都消耗體力**。

## 4. 貨幣

- **元寶**：初期唯一的抽卡貨幣（不區分免費 / 付費抽）。
- **金幣**：武將等級等基礎消耗，也是突破素材分解的產物。
- **卡牌強化素材**：獨立資源，不與金幣共用。

## 4.1 突破與成長實作（2026-10-07，`src/SanGuo.Core/Meta/`，數值皆為建議值）

**突破 = 重複抽到同一名武將**（1–5 隻，對應 1–5 星）。**屬性與特殊效果混搭**（業界做法），每名武將只需設計少數幾星的特殊效果，其餘星級套用屬性模板。

| 項目 | 規則 |
|---|---|
| 突破成本 | 抽到重複武將 → 轉為 20 碎片（任何稀有度皆同，= 一隻的份量）；每一星消耗 20 碎片，5 隻重複即滿星；**不耗金幣、不要求等級** |
| 星級模板 | 1★ 血量 +10%／**2★ 特殊**／3★ 攻擊 +10%／4★ 血量・攻擊・防禦 +15%／**5★ 特殊（終極）**；屬性加成相加、疊在等級成長之上 |
| 特殊效果 | 資料驅動（`BreakthroughTable`）：**強化版卡牌**（換掉套牌中的某張卡）、**新增專屬牌**、**被動**（核心尚未實作）；預設放在 2★ 與 5★，可自訂放在其他星 |
| 未設計的武將 | 沒有特殊效果時自動補替代屬性：2★ 血量 / 防禦 +8%、5★ 血量 / 攻擊 / 防禦 +10%，先上線再逐步補特殊效果 |
| 武將等級 | 消耗金幣（40×等級）與經驗書（等級/2+1）；上限 = 帳號等級（最高 60） |
| 等級屬性 | 血量 / 攻擊 / 防禦每級 +8%（1 級為 1.0，與 Demo 關卡校準一致）；速度 / 爆擊不成長 |
| 卡牌強化 | 消耗專用「卡牌強化素材」（3×(等級+1)）與金幣（200×(等級+1)）；每級效果 +15%；上限 5 級 |

張飛作為示範（`DemoBreakthroughs`）：2★ 燕人怒吼升級為「燕人怒吼・威」（護甲提高並抽 1 張牌）、5★ 當陽橋喝斷升級為「萬夫莫敵」（範圍擴大為全場）。每名武將只需設計這兩個特殊效果，設計量約為逐星設計的 40%。

已接進戰鬥（2026-10-07）：`HeroGrowth.BuildDef / BuildSlot` 把等級、突破（屬性與換牌 / 加牌）、卡牌強化（傷害 / 治療 / 護甲倍率）套到武將定義上，產生可直接入戰的 `HeroSlot`（戰鬥內等級固定 1，避免重複成長）。被動需要核心新增被動機制，尚未實作。

## 5. 待決

- 其餘武將的 2★ / 5★ 特殊效果設計；被動機制的核心實作；星級屬性模板的數值

- 經濟循環：金幣與強化素材的回收口
