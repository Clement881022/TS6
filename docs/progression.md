# 養成設計

> 狀態：草案（持續更新）。後續要擴展再擴展，初期只做最小集合。

## 1. 養成維度（初期）

| 維度 | 作用 | 消耗 |
|---|---|---|
| 武將等級 | 提升武將自身數值 | 待定（經驗類素材 / 金幣） |
| 卡牌強化 | 強化卡牌效果（傷害等） | 專用的「卡牌強化素材」（非金幣） |
| 突破（星級） | 解鎖卡牌強化版或新增效果 | 該武將的突破素材 |

戰鬥面的強化方向見 [combat.md](combat.md)。

## 2. 重複武將處理

- 抽到已擁有的武將 → 轉換為該武將的**突破素材**。
- 多餘的突破素材 → 可分解成金幣。

## 3. 素材產出與體力

- 主要靠資源副本（30–60 秒、可掃蕩）。
- 體力制（暫定）：主線、資源副本、高難關卡**都消耗體力**。

## 4. 貨幣

- **元寶**：初期唯一的抽卡貨幣（不區分免費 / 付費抽）。
- **金幣**：武將等級等基礎消耗，也是突破素材分解的產物。
- **卡牌強化素材**：獨立資源，不與金幣共用。

## 4.1 突破與成長實作（2026-10-07，`src/SanGuo.Core/Meta/`，數值皆為建議值）

**突破 = 重複抽到同一名武將**（1–5 隻，對應 1–5 星），每一星帶來**獨特效果**，不是單純的數值成長。

| 項目 | 規則 |
|---|---|
| 突破 | 抽到重複武將 → 轉為 20 碎片（任何稀有度皆同，= 一隻的份量）；每一星消耗 20 碎片，5 隻重複即滿星；**不耗金幣、不要求等級** |
| 每星效果 | 資料驅動（`BreakthroughTable`），三種類型：**強化版卡牌**（換掉套牌中的某張卡）、**新增專屬牌**、**被動**（由戰鬥核心依 id 實作，尚未接入）；星級不提供屬性加成 |
| 武將等級 | 消耗金幣（40×等級）與經驗書（等級/2+1）；上限 = 帳號等級（最高 60）；星級不影響等級上限 |
| 屬性成長 | 血量 / 攻擊 / 防禦每級 +8%（1 級為 1.0，與 Demo 關卡校準一致）；速度 / 爆擊不成長 |
| 卡牌強化 | 消耗專用「卡牌強化素材」（3×(等級+1)）與金幣（200×(等級+1)）；每級效果 +15%；上限 5 級 |

張飛已做完整五星作為示範（`DemoBreakthroughs`）：1★ 蛇矛破陣升級為「蛇矛・裂甲」（破甲 60%）、2★ 新增「長坂死守」、3★ 燕人怒吼升級（護甲提高並抽牌）、4★ 被動「挑釁期間額外減傷 10%」、5★ 當陽橋喝斷升級為全場範圍。其他武將待設計。

尚未接進戰鬥：`ScaleStats`、`CardEffectMultiplier`、`ResolveDeck` 已寫好，等戰鬥核心的關卡工作告一段落再接；被動需要核心新增被動機制。
