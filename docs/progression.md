# 養成設計

> 狀態：草案（持續更新）。後續要擴展再擴展，初期只做最小集合。

## 1. 養成維度（初期）

| 維度 | 作用 | 消耗 |
|---|---|---|
| 武將等級 | 提升武將自身數值 | 待定（經驗類素材 / 金幣） |
| 卡牌強化 | 強化卡牌效果（傷害等） | 專用的「卡牌強化素材」（非金幣） |
| 突破（星級） | 解鎖卡牌強化版或新增效果 | 該武將的突破素材 |

戰鬥面的強化方向見 [combat.md](combat.md)。

## 2. 重複武將處理

- 抽到已擁有的武將 → 轉換為該武將的**突破素材**。
- 多餘的突破素材 → 可分解成金幣。

## 3. 素材產出與體力

- 主要靠資源副本（30–60 秒、可掃蕩）。
- 體力制（暫定）：主線、資源副本、高難關卡**都消耗體力**。

## 4. 貨幣

- **元寶**：初期唯一的抽卡貨幣（不區分免費 / 付費抽）。
- **金幣**：武將等級等基礎消耗，也是突破素材分解的產物。
- **卡牌強化素材**：獨立資源，不與金幣共用。

## 4.1 實作（2026-10-07，`src/SanGuo.Core/Meta/HeroGrowth.cs`，皆為建議值）

| 項目 | 規則 |
|---|---|
| 武將等級 | 消耗金幣（40×等級）與經驗書（等級/2+1）；不能超過帳號等級與星級上限 |
| 等級上限 | 30 + 6×星級（五星 = 60 = 帳號等級上限） |
| 屬性成長 | 血量 / 攻擊 / 防禦倍率 = (1 + 0.08×(等級−1)) × (1 + 0.10×星級)；1 級 0 星為 1.0，與 Demo 關卡校準一致；速度 / 爆擊不成長 |
| 突破 | 需先升到目前等級上限；消耗該武將碎片（20 / 40 / 80 / 120 / 200）與金幣（1000×(星級+1)）；最高 5 星 |
| 卡牌強化 | 消耗專用「卡牌強化素材」（3×(等級+1)）與金幣（200×(等級+1)）；每級效果 +15%；等級上限 = 1 + 星級（最高 5） |
| 重複武將 | 轉為該武將碎片（R 5 / SR 10 / UR 20），見 gacha.md |
