## 4. 核心需要補的功能（依優先順序）

1. 定位改名（Assassin → Archer、Support → Healer）、趙雲改戰士、新增黃忠
2. **昏亂累積條**（含觸發後條上限遞增）
3. **火攻 / 瘟毒引爆**（立刻結算並擴散 / 依層數結算）、破甲加成
4. **屬性 buff**（屬性修正 + 持續回合）：坦克加防禦、軍師 buff
5. 敵方意圖補完：**蓄力大招、召喚、治療 / 增益**
6. 關卡目標：**保護目標、守回合**、擊殺指定
7. 擊退 / 拉扯 / 換位（站位為輔，可排在後面）
8. 資料改 ScriptableObject → JSON（關卡變多後必要）

## 4.1.1 教學關設定（2026-10-07 決定，取代前面「自動要輸」的做法）

- **教學關不開放自動戰鬥**（`BattleSetup.AutoAllowed = false`），讓玩家親手體驗該關要教的機制；自動戰鬥之後再開放。
- **隊伍固定、編隊鎖定**（`FormationLocked`）：用 R 級小兵湊數，只讓**一兩名武將**帶著該關教學的技能卡上場；編隊畫面之後再對玩家開放。
  - 第 1 關：純小兵（盾兵、義勇兵、弓手、醫士）
  - 第 2 關：張飛（嘲諷 + 防禦姿態）＋ 義勇兵 / 弓手 / 醫士
  - 第 3 關：鄉勇盾兵 ＋ 關羽（借牌：斷甲，**先登**）＋ 黃忠（破甲箭）＋ 醫士
- **該關的教學卡由寫死牌序保證開局在手上**（借牌仍帶「先登」）。
- 驗證改為兩個數字：「照教學打」與「忽略教學」勝率（自動勝率只當報表）。

## 4.1.3 新機制（第 5–10 關帶出）

- **蓄力大招**（`EnemyAbility.Charger`）：蓄力一回合（意圖顯示「蓄力中！」）、下回合放大招（攻擊 × `AbilityPower`）；被昏亂會打斷。
- **昏亂條**：每名敵人有昏亂條上限（雜兵 100、副將 60、渠帥 100…），卡牌提供昏亂值（`EffectType.StunGauge`）；條滿才眩暈 1 回合、條歸零，**上限 +50%**（`StunGrowth`）。張飛借牌「虎吼」+40、「當陽橋喝斷」+60（橫排）；昏亂不在初始套牌內，只在教學關借牌。
- **保護目標**（`HeroSlot.IsProtected`）：陣亡即失敗；可設開局血量比例（`StartHpPercent`，第 6 關鄉民 60%，讓「血量最低的隊友」自然選到他）。
- **引爆**（`EffectType.Detonate`）：只處理施放當下就在燃燒的敵人——立刻結算剩餘燒傷（威力 × 剩餘回合）、移除火攻、並把火攻擴散給相鄰（同排左右 / 同路前後）尚未燃燒的敵人；剛擴散到的不連鎖。
- **召喚**（`EnemyAbility.Summoner`）：每 `SummonEvery` 次行動召喚一名單位，優先填前排空格（由上往下），場上敵人達 `SummonCap` 就不再召喚；能力可組合（旗標），BOSS 張角 = 蓄力＋召喚（每 3 次行動：蓄力 → 大招 → 召喚）。
- **時限**：第 3 關（11）、第 7 關（3）、第 8 關（2）有回合上限，超過算失敗；第 7、8 關的限制是「照教學打」才趕得上。
- 蓄勢（Retain）用在 3 費的教學借牌（當陽橋喝斷）：第一回合費用不夠時留到下回合。

## 4.2 測試用 R 級小兵

只有普通攻擊的弱單位（6 張全是普通攻擊，攻擊力刻意壓低，避免輸出蓋過教學關的設計），方便測試時換上場、也當日後 R 卡的雛形：義勇兵（戰士）、鄉勇盾兵（坦克）、鄉勇弓手（弓手）、鄉勇醫士（醫療）。`HeroDef` 新增 `Rarity`（R / SR / UR）；現有六名武將**暫定標為 UR**（尚未定案，待與稀釋有關的決策）。編隊畫面有「待命武將」列，可自由換人（最多上場 4 人）。

## 4.3 大地圖與關卡流程

遊戲開啟先進**大地圖**（10 個節點）：打贏才開下一關、進度存本機（PlayerPrefs）；點關卡 → 編隊 → 開戰。戰鬥結束：勝利有「下一關 / 再打一次 / 回地圖」，敗北有「再打一次 / 調整編隊 / 回地圖」。尚未實作的關卡在地圖上顯示「未開放」。

## 5. 驗證方式（設計原則）

- **每關都是教學關：沒有善加利用該關教的機制，亂玩或自動戰鬥就會輸。** 第 1 關（純教學出牌）為例外。
- 每做一關要量化兩個數字：「能出就出」勝率要低（理想 ≤30%）、「照教學打」勝率要高（≥80%）；後者以優先度策略模擬。
- 精英 / BOSS 目標勝率不要求 40–70%，而是手動明顯優於自動。
