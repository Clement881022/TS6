> 2026-10-07 更新：破甲改成獨立百分比（不用層數）、神射手改為後排優先（見 combat.md）。第 3 關現為鐵甲力士血量 900 / 防禦 800、限 11 回合、破甲 50%・4 回合：**能出就出 35%、照教學打 92%（要求 100% 尚未達成）**。調參經驗：兩種策略都靠抽到破甲牌，差距主要來自「出牌順序」，單靠調數值很難同時壓低自動勝率又讓教學打 100%，需要機制層面的做法（例如讓破甲牌更穩定可得、或讓某個教學內容是自動戰鬥「做不到」的）。

**待修：第 2 關違反設計原則**（自動戰鬥 100% 會贏，挑釁 / 保護後排沒有存在價值），需要重新設計（見 6. 待決）。

程式在 `DemoContent.Level(n, seed)`；報表測試 `Chapter1Levels_WinRateReport`；第 3 關有斷言測試 `Level3_RequiresArmorBreak`（自動 ≤30%、照教學 ≥80%）。「照教學打」以 `AutoPlayer` 的優先度策略模擬（目前只有「先出破甲牌」）。

## 4.1.1 教學關設定（2026-10-07 決定，取代前面「自動要輸」的做法）

- **教學關不開放自動戰鬥**（`BattleSetup.AutoAllowed = false`），讓玩家親手體驗該關要教的機制；自動戰鬥之後再開放。
- **隊伍固定、編隊鎖定**（`FormationLocked`）：用 R 級小兵湊數，只讓**一兩名武將**帶著該關教學的技能卡上場；編隊畫面之後再對玩家開放。
  - 第 1 關：純小兵（盾兵、義勇兵、弓手、醫士）
  - 第 2 關：張飛（燕人怒吼，**先登**）＋ 義勇兵 / 弓手 / 醫士
  - 第 3 關：鄉勇盾兵 ＋ 關羽（斷甲，**先登**）＋ 黃忠（穿甲箭，**先登**）＋ 醫士
- **該關的教學卡一律帶「先登」**，開局一定在手上。
- 驗證改為兩個數字：「照教學打」與「忽略教學」勝率（自動勝率只當報表）。

現況：第 3 關照教學打 99%、忽略教學 4%（限 11 回合）；**第 2 關照教學打約 94%、忽略教學約 82%，挑釁的價值還不明顯**。原因：挑釁要花 1 費（每回合只有 3 費），而挑釁只是把傷害集中到坦克身上（總傷害不變，只靠坦克的防禦與護甲減傷），敵人火力調高後先倒的是坦克；調高護甲與敵人攻擊都沒有讓挑釁明顯勝出。需要機制層面的調整（見 6. 待決）。

## 4.2 測試用 R 級小兵

只有基礎牌的弱單位，方便測試時換上場、也當日後 R 卡的雛形：義勇兵（戰士）、鄉勇盾兵（坦克）、鄉勇弓手（弓手）、鄉勇醫士（醫療）。`HeroDef` 新增 `Rarity`（R / SR / UR）；現有六名武將**暫定標為 UR**（尚未定案，待與稀釋有關的決策）。編隊畫面有「待命武將」列，可自由換人（最多上場 4 人）。

## 4.3 大地圖與關卡流程

遊戲開啟先進**大地圖**（10 個節點）：打贏才開下一關、進度存本機（PlayerPrefs）；點關卡 → 編隊 → 開戰。戰鬥結束：勝利有「下一關 / 再打一次 / 回地圖」，敗北有「再打一次 / 調整編隊 / 回地圖」。尚未實作的關卡在地圖上顯示「未開放」。

## 5. 驗證方式（設計原則）

- **每關都是教學關：沒有善加利用該關教的機制，亂玩或自動戰鬥就會輸。** 第 1 關（純教學出牌）為例外。
- 每做一關要量化兩個數字：「能出就出」勝率要低（理想 ≤30%）、「照教學打」勝率要高（≥80%）；後者以優先度策略模擬。
- 精英 / BOSS 目標勝率不要求 40–70%，而是手動明顯優於自動。
