# 素材副本介面調整

依照使用者提供的紅線標註，加入包住分頁與五階卡片的深色金邊外框。
沿用專案既有背景、獎勵圖示與字型，本階段新增版面與文字識別，沒有新增繪製素材。

- 獎勵圖示下補上「元寶／銅錢／武將經驗」，體力消耗補上名稱。
- 裝備品階、掉率或碎片合成需求整合成標題下的一行。
- 解鎖條件縮短為「需通關第○階」或主線關卡編號，移除重複產出敘述與尚未通關提示。
- 卡片等高排列，鎖定卡片維持獎勵名稱的對比。
- 保留工作區既有素材副本／世界 Boss 分頁，移入外框。

## 驗證

使用 `tools/verify-unified-ui.ps1` 建置並擷取 1920×1080 與 1366×768 畫面。
每個解析度擷取 27 張，執行期與樣式錯誤均為 0；既有 HomeLayout 的 last-child 偽類警告各 1 次。
建置有既有 BattleStage 可空值與 CGCharacter shader 警告。

美術檢視：兩種解析度的素材副本截圖均確認五階卡片、獎勵名稱、掉落資訊、體力與按鈕完整，無文字裁切或重疊。
功能驗證範圍為建置、頁面切換、版面界線與樣式解析；截圖使用全階鎖定的離線帳號，未另外驗證挑戰及掃蕩操作。
未修改解鎖、獎勵、體力消耗、挑戰或掃蕩規則。

截圖與擷取清單保存在本目錄。
