# 主線第 1–6 章關卡與劇情總表

供審稿用：60 關的關名、目標、敵人與劇情摘要。關卡與敵人數值由 `src/SanGuo.Core/Content/Chapter1–6.cs` 產出，劇情原文在 `src/SanGuo.Core/Data/Story/Chapter1–6Story.cs`；第零章見 `docs/chapter0.md`。

## 貫穿 1.0 的線索

- **命牌**：主角穿越時握在手中的牌，每章末歸位一枚（第零章第一枚 → 第六章第七枚）。打倒帶著暗光的人時命牌會發熱、吸收暗光；第五章呂布沒有暗光，命牌卻因三兄弟並肩而歸位——命牌也回應羈絆。
- **天書與仙物**：南華老仙授張角天書三卷。黃巾的符紋黃布、渠帥的刀、段珪的玉如意等「仙物」都帶著同一種暗光。張角持一卷；張讓把一卷獻給董卓（李儒經手）；第三卷下落不明。
- **伏筆**：第六章末命牌異象中，群雄眼中閃著暗光，接到後續版本的架空章節（群雄魔化）。幕後主使未定（GDD 06 §4 待決），劇情沒有指名。
- **與演義的關係**：保留怒鞭督郵、溫酒斬華雄、三英戰呂布、三姓家奴等名場面；改動是讓劉關張參與救董卓、十常侍之亂、滎陽救曹等原本不在場的事件。董卓未在 1.0 戰死，由旁白交代初平三年死於呂布之手。

「戰前／戰後」為該關戰前劇情與首通後劇情的摘要。三星回合 = 第三星的限定回合數。
