# 戰鬥系統設計

> 狀態：草案（持續更新）。來源決策見 [README](../README.md)。

## 1. 設計意圖

- 以《超時空方舟》的「全隊共用資源」為骨架，結合《殺戮尖塔》的牌庫與敵方意圖預告。
- 個人開發可控：敵方 AI 刻意簡單、棋盤小（敵我共用 5x5）、規則可資料化。
- 差異化來源：武將定位決定牌庫構成，站位 + 範圍形狀製造「放空 / 命中」的取捨。

## 2. 棋盤與站位

- **敵我共用一張 5x5 棋盤**（Lane = 欄 0–4 左到右、Row = 列 0–4 上到下）。敵方起始在上兩列（0–1）、我方在下兩列（3–4），中間第 2 列是空地。
- 每格只能站一人；單位可以用移動卡走位（見 7.1），不能穿越任何單位，只能停在空格。
- 我方 4 名武將，敵方人數上限待定。
- **我方列陣只能選 3x2 格**（欄 1–3、列 3–4，常數見 `BattleSetup.FormationMin/Max*`）；敵方站位由關卡決定。舊關卡資料的「路 / 排」以 `DemoContent.HeroPos / EnemyPos` 映射到新座標。

## 3. 回合流程

1. 我方回合：回復費用（+3，可存，上限 10）→ 抽到 5 張手牌 → 出牌 → 結束回合並棄掉剩餘手牌。
2. 敵方回合：依預告的意圖行動。
3. 重複直到一方全滅。

敵方意圖在我方回合開始時即可見。

## 4. 卡牌

- 每名武將自帶一組固定套牌，全隊套牌合併為共用牌庫。
- 構成：固定 6 張，普通攻擊 + 依稀有度決定張數的職業高級牌（見 heroes.md 4.1）；武將另有被動。
- 費用：有 0–3 費的一般牌，也有 3 費以上的大招牌（可靠存費打出）。
- 武將陣亡：其卡牌不可打出，復活後恢復。

### 4.1 目標與範圍

卡牌描述 = **目標規則** + **射程（格距）** + **範圍形狀**。

- **射程**（`CardDef.Range`）：與施放者的曼哈頓格距上限。近戰普通攻擊 1 格（只能打周圍相鄰的敵人）、弓手 / 法師 / 軍師的普通攻擊 3 格；技能牌各自設定（狙擊 4、破甲箭 3、火計 3、治療 / 上盾 2）。
- 目標規則（`TargetRule`）：
  - `Enemy`：**玩家指定射程內的一格**（`PlayCard(card, targetTile)`），**空格也可以點（空放）**：照樣扣費、進棄牌堆，範圍形狀以該格為中心展開，只影響格上的敵人（可能一個都沒有）。沒指定格子（自動戰鬥）時挑範圍內最近的敵人，自動戰鬥不會空放。
  - `EnemyLowestHp`：射程內血量最低的敵人（自動）。弓手的「狙擊」使用。
  - `AllyLowestHp`：射程內血量比例最低的友軍（含自己）。
  - `Self` / `AllAllies` / `AllEnemies`：自身 / 全體，不受射程限制。
  - `MoveDest`：通用移動卡，見 7.1。
- 範圍形狀：單體、整排（目標所在列）、整欄（目標所在欄）、十字、全體，以所選中心目標為中心在 5x5 上展開（`Targeting.ExpandShape`）。
- 指定的格子不在射程內 → `PlayResult.OutOfRange`；自動選目標的牌（最低血量等）射程內沒有目標 → `NoTarget`，該牌不可打出（需先走位）。
- 敵人同樣受射程限制，見第 5 節。

### 4.2 自動戰鬥

- 由左至右依手牌順序，能出就出。

## 5. 敵方 AI

- 仍刻意保持簡單、可預測：每個敵人依序行動，「先走位、再攻擊」，意圖在我方回合可見。
- 近戰（射程 1）挑最近的我方單位；遠程（射程 3）優先挑**最後排**（Row 最大）且在射程內的單位，同條件取血量低者。
- 規劃：以移動力在可到達的格子（BFS，不可穿越單位）中找「能打到目標」且步數最少的位置，走過去後攻擊；誰都打不到就朝最近的我方單位靠近（意圖顯示為「逼近」）。
- 被挑釁時只考慮挑釁者（必要時為此走位）。
- 召喚：填離召喚者最近的空格（同距離優先靠近我方的列）。

## 6. 角色定位

| 定位 | 職責 |
|---|---|
| 坦克 | 擋傷害、挑釁；**以提升防禦（加防禦 buff）為主**，而非堆護甲（例：2 防禦 + 1 攻擊） |
| 戰士 | 前排輸出，能扛能打能破甲；什麼都會一點但樣樣不精 |
| 法師 | AOE；上火攻 / 瘟毒並引爆擴散 |
| 弓手 | 攻擊後排（取代刺客，更貼近三國題材） |
| 醫療 | **以治療、上護甲（盾）為主**（原「輔助」） |
| 軍師 | 提供群體 / 單體 buff；兼抽牌與費用 |

**屬性 buff 機制**：坦克的「加防禦」、軍師的 buff、破甲等，統一為「屬性修正 + 持續回合」（例：防禦 +30%，持續 2 回合），同一套程式實作。戰鬥內永久疊加屬性不納入基礎設計，之後可留給特定 UR 作為特色。

連招分工：軍師給資源與 buff → 醫療 / 法師 / 戰士上狀態（破甲、火攻、瘟毒、昏亂值）→ 弓手 / 戰士收割。

## 7. 節奏

- 資源副本：30–60 秒，可自動 / 掃蕩。
- 高難關卡：2–4 分鐘，手動。

## 7.1 單位與規則（已確認）

- 每名武將都是**獨立單位**，屬性（血量、移動速度等）各自獨立，沒有全隊共用血量。
- 護甲**保留**，直到被打掉才消失（不在回合結束時清除）。
- 敵方回合：所有敵人**依序行動**（由左至右）。
- 費用：每回合 +3，可存，上限 10；回合結束剩餘費用保留。
- **戰前編隊**：進關卡先在 3x2 列陣區排兵布陣，開戰後靠移動卡走位。
- **通用移動卡**：**不綁定任何武將**。隊伍每有一名帶牌的武將，開局就往牌堆洗入一張 0 費「移動」牌（沒有牌的保護目標不計）。打出時玩家**先選一名能移動的武將，再點目的地**（`PlayCard(card, destTile, mover)`），步數 ≤ 該武將的**移動力**；正交移動、不可穿越任何單位；陣亡 / 昏亂 / 四周無空格的武將不能選。教學關（寫死牌序）的移動卡排在腳本牌之後。舊的全隊移動按鈕（`MovesPerTurn` / `Battle.Move`）已移除。
- 推拉 / 換位 / 擊退：只作為特定武將的特色招式與特定關卡的互動，不是全隊通用。（待設計）
- **挑釁**：被挑釁的敵人不分路，強制攻擊該武將；持續回合數由該武將的卡牌決定。
- **攻擊範圍分類**（敵我皆有）：近戰射程 1 格、遠程 3 格；技能牌另有各自射程（見 4.1）。
- **敵方站位**：敵方同樣每格一人，位置由關卡設定；敵人會走位接近再攻擊（見第 5 節）。
- **移動力**（`Stats.Move`，原「速度」）：1–3 格，隨職業固定（天生屬性，不隨養成變動），決定移動卡的移動格數與敵人每回合的走位距離。

## 8. 牌庫循環（取後不放回）

- 全隊套牌（含通用移動卡）合併為抽牌堆；**首回合抽 7 張**（`HandSize`，降低開局沒有移動卡的機率），之後每回合抽 `DrawPerTurn`（3）張。
- **手牌不會在回合結束時棄掉**，手牌上限 10 張；抽到上限就停止。
- **抽牌堆抽完就沒有了，棄牌堆不會洗回**（用過的牌只進棄牌堆 / 消耗堆供顯示）。蓄勢（Retain）關鍵字因此不再有效果。
- 費用規則不變：每回合 +3、可存、上限 10。

## 9. 卡牌關鍵字（三國風命名，建議值）

| 關鍵字 | 效果 | 對應常見機制 |
|---|---|---|
| 破釜 | 打出後本場戰鬥移除（一次性） | 消耗 |
| 蓄勢 | 回合結束不棄，留在手中 | 保留 |
| 先登 | 開戰時必在起手牌 | 固有 |

名稱為暫定，可再改；規則先以資料欄位實作（如 `exhaust` / `retain` / `innate`），顯示名稱獨立設定。

## 10. 範圍形狀（第一版）

以中心目標展開：單體、橫排（同排）、縱列（同路）、十字、全體。
後續擴充：前後兩排、隨機 N 個、最後排。

## 11. 狀態效果（第一版，控制在 6–8 個，建議值）

| 狀態 | 效果 |
|---|---|
| 護甲 | 先吸收傷害，保留到被打掉為止 |
| 火攻 | 持續傷害（灼燒） |
| 瘟毒 | 持續傷害（中毒），與火攻區分衰減方式 |
| 昏亂 | 眩暈：跳過行動 / 不可出牌（待定） |
| 破甲 | 降低防禦：**不是層數**，每次施加都是獨立一筆（百分比＋持續回合），各筆各自計時、彼此乘算（例：40% 與 15% 並存 → 防禦 ×0.6×0.85） |
| 挑釁 | 嘲諷：敵方攻擊強制選擇該武將（優先於「最前排」目標規則）；**挑釁期間挑釁者受到的傷害 -30%** |

### 11.1 狀態引爆（已確認方向）

連招骨架：基礎走「狀態引爆」，UR 另有出牌序列型機制（見 README 決策紀錄）。每種狀態只對應一種引爆方式，並依狀態決定是否消耗：

| 狀態 | 引爆方式 | 是否消耗 |
|---|---|---|
| 破甲 | 純粹降低防禦（多筆獨立百分比、乘算），無額外引爆；收益隨防禦公式遞減 | 不消耗，各筆持續回合結束才各自消失 |
| 火攻 | 立刻結算剩餘燒傷，並擴散給相鄰敵人 | 消耗 |
| 瘟毒 | 依層數一次結算（層數越多越痛） | 消耗 |
| 昏亂 | **累積制**：敵人有「昏亂條」，累積滿才觸發眩暈（跳過行動 / 不可出牌） | 觸發後條歸零 |

**昏亂累積制**：避免對 BOSS 過強。每個敵人有昏亂條上限（BOSS 遠大於雜兵），卡牌提供昏亂值而非直接眩暈；**防連控採「條上限遞增」**：每次觸發後該敵人的昏亂條上限 +50%（比例為資料欄位），越控越難控。敵人資料只需「昏亂條基礎上限」與「遞增比例」兩個欄位。

## 12. 敵方意圖類型

攻擊、防禦、治療、增益、移動、召喚、蓄力大招。（**已實作**：治療、蓄力大招、召喚（見 demo-chapter1.md 4.1.3）。治療細節：：`EnemyAbility.Healer`，每回合治療血量比例最低的受傷友軍，治療量 = 攻擊 × 倍率；沒人受傷時照常攻擊。）敵方 AI 維持簡單（見第 5 節），意圖在我方回合可見。

## 13. 關卡目標

- 勝利：擊殺全部敵人 / 擊殺指定敵人 / 守住回合數 / 保護目標存活。
- 失敗：我方全滅 / 保護目標陣亡 / 超過回合數限制。

## 13.1 數值與傷害（已確認方向）

- **屬性**：血量、攻擊、**謀略**、防禦、閃避、移動力、爆擊、爆傷。
- **謀略（`Stats.Int`）**：法系（法師 / 醫療 / 軍師，以及會治療的敵人）的**治療、護甲、法術傷害、持續傷害（灼燒 / 瘟毒）威力**吃謀略，並讓**增益（攻擊 / 防禦 / 暴擊提升）與破甲**的強度乘上 `謀略 / 150`（`DamageCalc.CasterReference`）；弓手、戰士、坦克仍吃攻擊力，以此與「弓級力」做出區分。法系的鼓舞（攻擊提升）同時提高其有效謀略。法系的攻擊力不再參與卡牌結算（保留作為物理攻擊屬性）。
- **卡牌傷害寫倍率**（例：120% 攻擊力），讓武將等級與突破直接影響卡牌強度。
- **公式風格**：乘法減傷（類 LoL）：`傷害 = 攻擊 × 倍率 × 100 / (100 + 防禦)`，再套用爆擊、破甲等乘區。防禦收益遞減，數值膨脹時較穩定。
- **隨機**：有爆擊與閃避；使用**帶種子的隨機數**，同一種子可重播（伺服器驗證用，仍可確定性復現）。
- **移動力**屬性決定「移動」卡牌的移動範圍（1–3 格，隨職業固定，見 7.1）。

## 14. 待決

- 棋盤尺寸最終值（目前 5x5 共用棋盤、列陣區 3x2）
- 敵方人數上限、BOSS 是否佔多格（尚未限制，兩種都可）
- 昏亂條的數值（雜兵 / 精英 / BOSS 基礎上限與遞增比例）；狀態疊加與持續回合
- 爆擊 / 閃避的上下限與是否可被卡牌保證觸發
- 多個挑釁同時存在時敵人選誰（最近 / 最後施放 / 最高優先）
- 移動是否能穿過自己人（目前不能穿越任何單位）
- 牌堆不重洗後，長期戰（教學關 / BOSS）的牌量是否足夠；`DrawPerTurn` 與敵人強度是否需要再調（目前以 `DemoContent.TutorialEnemyScale` 校準）
- 護甲疊加是否有上限（保留制下需避免坦克無限堆疊）
- 自動戰鬥「能出就出」是否需要例外（如保留費用給大招牌）
- 敵人類型設計（對策型 SR 要能對應到的戰況）
- 費用 3 以上的大招牌的稀有度與取得方式
