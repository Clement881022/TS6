# 戰鬥系統設計

> 狀態：草案（持續更新）。來源決策見 [README](../README.md)。

## 1. 設計意圖

- 以《超時空方舟》的「全隊共用資源」為骨架，結合《殺戮尖塔》的牌庫與敵方意圖預告。
- 個人開發可控：敵方 AI 刻意簡單、棋盤小（雙方各 5x2）、規則可資料化。
- 差異化來源：武將定位決定牌庫構成，站位 + 範圍形狀製造「放空 / 命中」的取捨。

## 2. 棋盤與站位

- 雙方各一張 5x2 棋盤，只能在自己的棋盤內移動。
- 每格只能站一人。
- 我方 4 名武將，敵方人數上限待定。
- 站位在**戰前編隊**時決定，戰鬥中不能自行移動（見 7.1）；擊退 / 拉扯 / 換位只出現在特定武將的技能或特定關卡機制。

## 3. 回合流程

1. 我方回合：回復費用（+3，可存，上限 10）→ 抽到 5 張手牌 → 出牌 → 結束回合並棄掉剩餘手牌。
2. 敵方回合：依預告的意圖行動。
3. 重複直到一方全滅。

敵方意圖在我方回合開始時即可見。

## 4. 卡牌

- 每名武將自帶一組固定套牌，全隊套牌合併為共用牌庫。
- 構成：普攻 / 防禦 / 治療 / 移動等基礎牌 + 武將專屬主動牌；武將另有被動。
- 費用：有 0–3 費的一般牌，也有 3 費以上的大招牌（可靠存費打出）。
- 武將陣亡：其卡牌不可打出，復活後恢復。

### 4.1 目標與範圍

卡牌描述 = **目標規則** + **範圍形狀**，打出後自動判定，玩家不選格。

- 目標規則：路由上到下編號（第 1 路在最上方）。**同路優先**，取該路最前排（弓手類取最後排）的敵人作為**中心目標**；**同路沒人就由上往下找第一條有人的路**，因此第 1 路是預設的「坦克位」，誰站那裡誰就吃到沒有對手的火力。雙方（敵人也一樣）使用同一套規則。
- 範圍形狀（例）：單體、橫排、縱列、十字、全體……（清單待補），以中心目標為中心展開。
- **後排優先（弓手 / 遠程，雙方通用）**：不分路，先找最後一排，由上往下取第一個；最後一排沒人才往前一排，同樣由上往下。（「瞄最脆弱的」之類的選目標方式屬於個別武將 / 敵人的特性，不是預設規則。）
- 只有對方全滅（戰鬥已結束）才會沒有目標；範圍外溢的格子可以是空格。
- 敵人因此不再需要「打不到就移動」；挑釁的敵人不分路，強制攻擊挑釁者。
- 棋盤尺寸（暫定 5x2）採資料驅動，不寫死，方便調整。

### 4.2 自動戰鬥

- 由左至右依手牌順序，能出就出。

## 5. 敵方 AI

- 刻意設計為簡單：永遠有目標可打（同路優先，沒人就由上往下找），不再需要移動。
- 優點：行為可預測，便於玩家讀意圖與設計關卡；實作與平衡成本低。

## 6. 角色定位

| 定位 | 職責 |
|---|---|
| 坦克 | 擋傷害、挑釁；**以提升防禦（加防禦 buff）為主**，而非堆護甲（例：2 防禦 + 1 攻擊） |
| 戰士 | 前排輸出，能扛能打能破甲；什麼都會一點但樣樣不精 |
| 法師 | AOE；上火攻 / 瘟毒並引爆擴散 |
| 弓手 | 攻擊後排（取代刺客，更貼近三國題材） |
| 醫療 | **以治療、上護甲（盾）為主**（原「輔助」） |
| 軍師 | 提供群體 / 單體 buff；兼抽牌與費用 |

**屬性 buff 機制**：坦克的「加防禦」、軍師的 buff、破甲等，統一為「屬性修正 + 持續回合」（例：防禦 +30%，持續 2 回合），同一套程式實作。戰鬥內永久疊加屬性不納入基礎設計，之後可留給特定 UR 作為特色。

連招分工：軍師給資源與 buff → 醫療 / 法師 / 戰士上狀態（破甲、火攻、瘟毒、昏亂值）→ 弓手 / 戰士收割。

## 7. 節奏

- 資源副本：30–60 秒，可自動 / 掃蕩。
- 高難關卡：2–4 分鐘，手動。

## 7.1 單位與規則（已確認）

- 每名武將都是**獨立單位**，屬性（血量、移動速度等）各自獨立，沒有全隊共用血量。
- 護甲**保留**，直到被打掉才消失（不在回合結束時清除）。
- 敵方回合：所有敵人**依序行動**（由左至右）。
- 費用：每回合 +3，可存，上限 10；回合結束剩餘費用保留。
- **戰前編隊（取代全隊移動按鈕）**：進關卡先排兵布陣（5 路 × 前後排），戰鬥中不能自行移動。試玩後認為全隊移動按鈕雞肋又廉價，已停用（核心 `MovesPerTurn` 預設 0，移動 API 保留供日後技能使用）。第 1 路是預設坦克位，編隊成為開局決策。
- 推拉 / 換位 / 擊退：只作為特定武將的特色招式與特定關卡的互動，不是全隊通用。（待設計）
- **挑釁**：被挑釁的敵人不分路，強制攻擊該武將；持續回合數由該武將的卡牌決定。
- **攻擊範圍分類**（敵我皆有）：
  - 近戰：前方有人時只能先打前方的目標。
  - 遠程：可選擇後排，或只能打後排（依單位 / 卡牌設計）。
- **敵方站位**：敵方同樣每格一人，位置由關卡設定；敵人不需要移動即可攻擊。
- **移動速度**：1–3 格，隨職業固定（天生屬性，不隨養成變動）。

## 8. 牌庫循環

- 全隊套牌合併為抽牌堆；每回合開始棄掉剩餘手牌並抽到 5 張。
- 抽牌堆不足時，棄牌堆洗回抽牌堆繼續抽。

## 9. 卡牌關鍵字（三國風命名，建議值）

| 關鍵字 | 效果 | 對應常見機制 |
|---|---|---|
| 破釜 | 打出後本場戰鬥移除（一次性） | 消耗 |
| 蓄勢 | 回合結束不棄，留在手中 | 保留 |
| 先登 | 開戰時必在起手牌 | 固有 |

名稱為暫定，可再改；規則先以資料欄位實作（如 `exhaust` / `retain` / `innate`），顯示名稱獨立設定。

## 10. 範圍形狀（第一版）

以中心目標展開：單體、橫排（同排）、縱列（同路）、十字、全體。
後續擴充：前後兩排、隨機 N 個、最後排。

## 11. 狀態效果（第一版，控制在 6–8 個，建議值）

| 狀態 | 效果 |
|---|---|
| 護甲 | 先吸收傷害，保留到被打掉為止 |
| 火攻 | 持續傷害（灼燒） |
| 瘟毒 | 持續傷害（中毒），與火攻區分衰減方式 |
| 昏亂 | 眩暈：跳過行動 / 不可出牌（待定） |
| 破甲 | 降低防禦：**不是層數**，每次施加都是獨立一筆（百分比＋持續回合），各筆各自計時、彼此乘算（例：40% 與 15% 並存 → 防禦 ×0.6×0.85） |
| 挑釁 | 嘲諷：敵方攻擊強制選擇該武將（優先於「最前排」目標規則） |

### 11.1 狀態引爆（已確認方向）

連招骨架：基礎走「狀態引爆」，UR 另有出牌序列型機制（見 README 決策紀錄）。每種狀態只對應一種引爆方式，並依狀態決定是否消耗：

| 狀態 | 引爆方式 | 是否消耗 |
|---|---|---|
| 破甲 | 純粹降低防禦（多筆獨立百分比、乘算），無額外引爆；收益隨防禦公式遞減 | 不消耗，各筆持續回合結束才各自消失 |
| 火攻 | 立刻結算剩餘燒傷，並擴散給相鄰敵人 | 消耗 |
| 瘟毒 | 依層數一次結算（層數越多越痛） | 消耗 |
| 昏亂 | **累積制**：敵人有「昏亂條」，累積滿才觸發眩暈（跳過行動 / 不可出牌） | 觸發後條歸零 |

**昏亂累積制**：避免對 BOSS 過強。每個敵人有昏亂條上限（BOSS 遠大於雜兵），卡牌提供昏亂值而非直接眩暈；**防連控採「條上限遞增」**：每次觸發後該敵人的昏亂條上限 +50%（比例為資料欄位），越控越難控。敵人資料只需「昏亂條基礎上限」與「遞增比例」兩個欄位。

## 12. 敵方意圖類型

攻擊、防禦、治療、增益、移動、召喚、蓄力大招。敵方 AI 維持簡單（見第 5 節），意圖在我方回合可見。

## 13. 關卡目標

- 勝利：擊殺全部敵人 / 擊殺指定敵人 / 守住回合數 / 保護目標存活。
- 失敗：我方全滅 / 保護目標陣亡 / 超過回合數限制。

## 13.1 數值與傷害（已確認方向）

- **屬性**：血量、攻擊、防禦、閃避、速度、爆擊、爆傷。
- **卡牌傷害寫倍率**（例：120% 攻擊力），讓武將等級與突破直接影響卡牌強度。
- **公式風格**：乘法減傷（類 LoL）：`傷害 = 攻擊 × 倍率 × 100 / (100 + 防禦)`，再套用爆擊、破甲等乘區。防禦收益遞減，數值膨脹時較穩定。
- **隨機**：有爆擊與閃避；使用**帶種子的隨機數**，同一種子可重播（伺服器驗證用，仍可確定性復現）。
- **速度**屬性決定「移動」卡牌的移動範圍（1–3 格，隨職業固定，見 7.1）。與資料表中的 moveSpeed 為同一項。

## 14. 待決

- 棋盤尺寸最終值（暫定 5 路 × 2 排，雙方面對面、同路對應）
- 敵方人數上限、BOSS 是否佔多格（尚未限制，兩種都可）
- 昏亂條的數值（雜兵 / 精英 / BOSS 基礎上限與遞增比例）；狀態疊加與持續回合
- 爆擊 / 閃避的上下限與是否可被卡牌保證觸發
- 多個挑釁同時存在時敵人選誰（最近 / 最後施放 / 最高優先）
- 移動是否能穿過自己人（每格只能一人，換位規則）
- 護甲疊加是否有上限（保留制下需避免坦克無限堆疊）
- 自動戰鬥「能出就出」是否需要例外（如保留費用給大招牌）
- 敵人類型設計（對策型 SR 要能對應到的戰況）
- 費用 3 以上的大招牌的稀有度與取得方式
