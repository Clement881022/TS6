# 主城角色、出征 hover 與資源框調整

日期：2026-10-10

## 實際變更

- 出征保留原有金色外框；hover 僅旗幟放大至 1.06，140ms ease-out。按鈕、文字的大小與位置固定，移出後旗幟回復。
- 左側立繪容器寬度由 540 改為 648，約放大 20%；高度 792，向左微調並維持底部對齊。
- 切換角色改成 68×68 圓形雙向箭頭圖示，位於角色右下角，保留「切換角色」提示。
- 主打卡由只取第一位 UP 武將改為顯示角色池的 UP 武將；目前「燕人武聖」同時呈現張飛與關羽。不修改角色池或抽取規則。
- 右上資源框高度由 116 縮為 82，減少上下留白，圖示與數字尺寸維持原設定。
- 使用既有背景、旗幟與立繪；切換圖示使用字型符號，本次沒有新增點陣美術。

## 功能驗證

Unity 6000.3.25f1 測試副本打包成功。測試位於 build/ui-layout-client-copy，與原專案同樣載入 HomeLayout；測試用截圖與驗證程式沒有接入原專案。

1920×1080、1600×900 的實際 Unity 渲染驗證：

- 張飛與關羽顯示元素都有立繪貼圖。
- 資源框解析高度為 82（容許 Unity 像素對齊），角色容器寬度 648。
- hover 旗幟寬度比例 1.06；按鈕與文字 worldBound 維持固定；金色框保留，移出後圖示回復原尺寸。
- 切換鍵沒有文字標籤，包含箭頭圖示。測試副本在非持久化 ProfileView 加入第二位角色顯示資料，確認送出按鈕事件後立繪貼圖確實改變；測試資料未加入正式遊戲。
- 最終 player.log 沒有 Exception 或樣式解析錯誤。

較早測試副本缺少 HomeLayout 載入而高度檢查失敗，補上後修正。後續 hover 驗證發現文字自動寬度由 105 變為 108，已固定文字寬度與字重後重測通過。失敗的中間結果不列為通過依據。

原始驗證輸出位於 build/home-adjustment-review/{1920x1080,1600x900}/verification.txt 與 player.log。
