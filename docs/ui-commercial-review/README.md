## 主城 A／B 的可比較基準

兩稿使用相同的原始城景、玩家頭像、七個入口與示範資料：主公 Lv.1、經驗 0/65、體力 62/62、銅錢 5,000、元寶 2,000、第零章涿縣盜匪、0-1 涿縣村口、章節進度 0/10、編隊第 9 關開放。沒有新增功能或促銷入口。

| 項目 | A 輕巧青玉金邊 | B 圓潤銅金徽章 |
| --- | --- | --- |
| 面板 | 低紋理青玉漸層、1 單位細邊 | 青玉漸層、2–3 單位銅邊與柔和厚度 |
| 面板圓角 | 12 | 22 |

| 導航 | 原圖直接展示，少量陰影 | 原圖放入圓形徽章容器 |
| 字級 | 資訊 16、標題 25、主操作 21 | 與 A 相同，排除字級差異造成的偏好 |
| 色彩 | 青玉 #173B38、細金 #C6A96B | 青玉 #173C32、銅金 #BD955C |

16:9 使用 800×450 邏輯畫布，20:9 使用 1000×450。兩者保留相同高度與字級，寬螢幕增加左右空間與導航間距。背景為同一原圖的置中 cover 取景，20:9 會裁掉部分上下場景，並非重新生成背景。

主要按鈕至少 48×48；主城左右示意安全區為 24，20:9 為 40，底部為 18。這些數值是提案基準，正式版必須讀取裝置安全區，不可把這組固定值當作所有手機的瀏海規格。

## 戰鬥手機 UX 建議

推薦「棋盤常駐、資訊按需展開、點牌後點目標」：

1. 常駐：關卡與回合、四人頭像／血條、棋盤、敵方簡短行動預告、手牌、費用與結束回合。
2. 隊伍：完整名字、生命數值、護盾及狀態改為點按展開；護送 NPC 保留在隊伍列，不省略護送狀態。
3. 手牌：一次顯示五張完整卡，保持固定可點寬度；其餘卡透過水平滑動或左右按鈕取得。七張示範牌全部保留。
4. 點牌：手牌列暫時改為該卡效果、費用及取消入口，直接高亮目標類型，不增加「選擇目標」的額外步驟。
5. 點目標：由既有戰鬥規則判定合法性並施放；本原型僅回饋選擇結果，不計算傷害或消耗費用。
6. 取消：點取消回到手牌，保留水平位置；切換單位詳情時取消選牌。
7. 收納：重置視角、撤退、重來、說明放進選單；正式版撤退／重來需確認。測試用直接勝利不提供為玩家操作。

棋盤示意保留專案預設 5×5。隊伍位置與敵軍預告僅為布局樣本，不是本輪重新定義的配置或 AI 規則。示範生命、費用與卡牌倍率參照使用者截圖，正式接入時全部取自當場戰鬥資料。

棋盤目標操作區至少 44×44，其餘按鈕至少 48×48。選牌效果顯示在原手牌區，不遮住棋盤；展開單位資訊可暫時遮住部分棋盤，關閉即恢復。

另一種可行方式是「棋盤全螢幕、手牌抽屜」。它讓棋盤更大，但每次查牌需開啟抽屜，也容易忘記剩餘手牌；因此本輪採常駐五張的方案。拖牌施放可列為後續可選捷徑，不能成為唯一操作方式。

### Claude Code 接入規格

- 先建立觸控 UI 的 idle／selected-card／unit-detail／menu 顯示狀態，讓收起與取消行為一致。
- 資料沿用既有單位、生命、護盾、狀態、手牌、費用、牌堆與敵方預告資料；不新增戰鬥 API 或修改規則。
- 目標範圍、不可用原因、移動步驟、無目標卡與施放失敗由原系統提供；不可照原型中僅檢查敵我類型的示例判定。
- 移動卡原型不模擬「選我方單位再選目的地」，正式接入需保留既有完整流程。
- 動畫／敵方回合期間鎖定施放與結束回合；失敗保留可重試資訊，不把失敗當成功收牌。
- Codex 提供版面、素材引用與狀態樣式；Claude Code 處理觸控狀態、事件與規則接入。

本輪未使用 imagegen；確認既有底材足夠後，採可編輯 UI 元件製作，確保原圖、數值與中文字在 A／B 間一致。沒有新圖片生成提示詞。

## 驗證結果與限制

- 10 張 PNG 均已目視檢查；16:9、20:9 的主城與戰鬥輸出為 2 倍像素密度。元件圖高度依實際內容輸出，尺寸記於 verification.json。
- 主城：方向切換、比例切換、安全區、導航點按狀態與主操作回饋通過。
- 戰鬥：點牌即展開、敵我目標提示、錯誤目標回饋、取消、隊伍詳情、滑動至末張手牌、選單與結束回合回饋通過。
- 800×450、1000×450 的瀏覽器觸控模擬完成點牌與點友軍目標流程；未依賴 hover。
- 所輸出完整場景的可見操作區符合本輪 44／48 邏輯尺寸基準，常態與選牌狀態無操作區重疊或越界；瀏覽器錯誤 0。
- 沒有啟動 Unity、沒有執行正式戰鬥、沒有以 Windows 截圖宣稱手機硬體驗收。
- 約 6 吋手機的實際可讀性、OS 安全區、手指遮擋、觸控誤差與 FPS 尚未驗收；這些必須在方向選定、接入後以目標手機確認。
- 正式戰鬥接入需驗收十張手牌、長文案、資源不足、無合法目標、護盾／陣亡／狀態疊加、護送目標、移動與無目標卡、敵方回合及施放失敗。

## 開啟與重現

可直接以瀏覽器開啟 index.html，素材相對路徑依專案目錄存放。可點選預覽需保留同一專案的 ChibiSkin 與 Fonts。

輸出工具依賴 Node.js、Playwright 與本機 Edge；可透過 `UI_REVIEW_BROWSER` 指定其他 Chromium 執行檔。使用桌面提供的 bundled Node 時，將 `NODE_PATH` 設為其 node_modules 路徑，再執行：

```powershell
node docs/ui-commercial-review/render.cjs
```

以本機瀏覽器預覽：

```powershell
node docs/ui-commercial-review/render.cjs --serve
```

工具只啟動 127.0.0.1 靜態預覽，不呼叫遊戲後端、不操作帳號、不對外發布。

後續順序：使用者看圖選 A／B 或指定修改 → 主城實機接入與手機驗收 → 戰鬥顯示與觸控接入 → 武將／養成 → 其他功能頁。本輪不擅自替使用者選定最終美術方向。
