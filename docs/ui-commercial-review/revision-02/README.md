## 對應修改

| 使用者回饋 | 新版處理 |
| --- | --- |
| 主線資訊重複 | 只顯示章節、完成數、下一關名稱、出征與編隊解鎖提示；移除第二組章節敘述、額外關卡列與重複進度軌道 |
| 副本與世界 Boss 不需要各占大入口 | 主城合併為「挑戰」，點開後保留素材副本與世界 Boss 兩個目的地；底部改為六個入口 |
| 不要分隔線 | 底部導航取消分組直線與其他入口分隔線 |
| 按鈕文字置中 | 出征、入口、挑戰選項、結束回合及原型操作按鈕均置中 |
| 圖片沒有置中 | 依既有 PNG 主體的透明度連通範圍校準縮放與位置，六個圖示共用 42 單位容器；未改寫原圖 |
| 黑灰色比綠色好看 | 主介面使用炭黑與中性灰，暖金只用於主要操作、費用和少量重點 |
| 底欄貼底而且不要框 | 背景延伸到左、右、下緣，沒有圍框或圓角；實際按鈕保留安全區內距 |
| 戰鬥需要 3D 模型 | 使用既有 Unity 3D 模型與棋盤實機截圖作設計底材，不再使用頭像平面棋盤 |

## 配置與元件基準

設計畫布為 800×450 與 1000×450 邏輯單位，輸出 PNG 為兩倍尺寸。20:9 增加場景橫向留白，保持文字與操作大小，不把整套 UI 拉寬。文字、數值與按鈕仍是 HTML 元件。

| 項目 | 規格 |
| --- | --- |
| 主底色／面板 | `#202124`／`#27282b` |
| 主要文字／次要文字 | `#f2eee5`／`#bbb7af` |
| 強調色 | `#d4b477`，主要操作漸層 `#ead39c` 至 `#d2ad66` |
| 主要字級 | 入口與卡名 16、資源 17、帳號 18、主要操作 20、關卡名 26 |
| 次要字級 | 13–14；提案標記與牌堆數 11，不承載關鍵操作資訊 |
| 主城底欄 | 高 92；按鈕 104×74；圖示容器 42×42，主體最大 38 |
| 主線面板 | 寬 226，內距 16；出征高 50 |
| 戰鬥手牌區 | 高 112；手牌高 90，每屏五張，可水平滑動或用兩側按鈕切換 |
| 觸控區 | 可見操作至少 48×48；隊伍入口 52×52；目標示意區 48×48 |
| 安全區 | 主城橫向內距 24／40，下方內容內距 16；正式版改採裝置回報的安全區 |
| 狀態 | 原型包含預設、按下、選中、焦點；停用樣式已定義，正式版狀態由既有功能決定 |

主城的「出征」具有最高操作權重，導航縮為圖示加單行文字。戰鬥左側僅常駐隊伍頭像與簡短生命條，完整生命值點按取得；手牌只常駐費用、人物與卡名，效果在選牌後取代原手牌區，取消後回到手牌。敵方原有模型上方標籤來自截圖，這一輪沒有額外疊加第二份敵方資料。

## 來源與接入邊界

沿用城景、人物頭像及圖示：`client/Assets/Resources/ChibiSkin/`；沿用字體：`client/Assets/Resources/Fonts/CjkFontMedium.ttf`、`ChibiDisplay.ttf`。

戰場底材：`docs/ui-layout-review/1920x1080/36-battle-start.png`，關卡 0-2 山賊探子。HTML 只裁出戰場區域並疊加新介面，沒有新增或重製模型，也沒有運行 3D 動畫；截圖中的模型標籤和生命條尚屬底圖。新製內容為黑灰元件、版面、導航整併與配置原型。

正式接入時保留 Unity 的 3D 模型、動作、棋盤與既有戰鬥規則。截圖不得當作正式戰場資產；目標示意熱區不得直接照固定座標接入，應由相機投影或既有點選機制取得。隊伍生命、費用、牌堆、章節進度與解鎖條件均綁定既有資料。

挑戰合併只改入口位置，保留兩個目的地。卡牌目標流程只是配置示範，嘲諷、攻擊與移動的實際目標類型、合法性及結算交由既有規則；不得依此原型另定規則。涉及點按展開、手牌瀏覽、投影選取與入口跳轉的功能接入由 Claude Code 依本規格實作；美術與顯示版面可由 Codex 接入。

## 驗證紀錄

功能／配置：六張輸出均通過可見按鈕至少 48 單位、未超出畫布、未互相重疊與文字置中檢查。主城底欄確認左／右／下間隙為零、無邊框與圓角、六入口。兩個挑戰目的地、選牌到敵軍目標、隊伍詳情、最後一張手牌及戰鬥選單可操作；800×450、1000×450 模擬觸控均通過。瀏覽器腳本錯誤為零。

美術：已檢視兩種比例的主城、3D 戰場、挑戰入口及選牌輸出，確認圖示主體置中、主城地標可見、主要操作辨識清楚、3D 人物與棋盤保留。這是第二版提案，仍需使用者看圖選定方向；尚未完成約六吋手機硬體的閱讀／誤觸驗收，不宣稱已達商用品質。

重新輸出：使用已安裝 Playwright、sharp 的 Node 執行 `render.cjs`，本機 Edge 產生截圖與報告；加 `--serve` 只開本機預覽，不發布。瀏覽器路徑可用 `UI_REVIEW_BROWSER` 覆寫。
