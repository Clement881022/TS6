## 視覺與接入規格

畫布 800×450／1000×450；20:9 只增加場景寬度與導航間距，不放大或拉長圖示文字。底欄高 92，導航高 76，圖示容器 46、主體最大 42，標籤 16；相鄰分隔線 1×36，顏色 `#b8a99155`。出征區寬 156，按鈕高 56，暖金漸層、8 單位圓角，字級 23。主要文字 `#f3ecde`，底色 `#242427`，強調 `#d7b677`。

主體最大尺寸一致不等於所有物件面積相同；本輪以輪廓可辨識、基線與中心穩定為判定，不藉由縮小透明畫布假裝置中。`icon-focus.json` 保存原圖中的主體像素範圍，CSS 僅顯示相應視窗，沒有修改原圖像素。

可見可點按操作至少 48×48；玩家／資源資訊列保留觸控高度。左右安全內距 24／40，下緣操作內距至少 16。正式接入改用裝置實際安全區回報；底欄背景延伸至邊緣，操作不能延伸至系統手勢區。

原型提供預設、按下、選中、鍵盤焦點與彈層。選中以金色文字和細底標示呈現，沒有方形高亮色塊。資訊詳情、功能整頁切換與導航選中皆為原型示意，不改主線、解鎖、費用、獎勵或戰鬥規則。

需要 Claude Code 接入的功能：主線詳情展開、帳號／資源資訊顯示、挑戰兩目的地切換。遊戲資料仍由原有系統提供。Codex 可處理素材與視覺顯示接入；本稿沒有改執行期程式。
