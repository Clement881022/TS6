# 張飛裝備第九階段（2026-10-09）

新增立體肩甲殼、金属嵌邊、獸首浮雕和前臂護甲。第一輪光滑玩具造型未採用；改製與立繪一致的赤眼金獸 UV 表面，配合封閉浮雕網格，而非只在原身體上換圖。
