# 全武將基本 3D 覆蓋階段

依使用者最新要求，本輪完成全武將基本模型後停止，不繼續精修。基本覆蓋不等於商用美術驗收通過。

## 完成範圍

`HeroRoster` 的 29 個可抽取／故事武將 ID 全部具有同 ID 的 `ProductionCharacters/<ID>.prefab`；此資源目錄共有 57 個角色 Prefab。補齊原本缺少正式模型的 24 個 ID，包含夏侯惇、呂布、公孫瓚、華雄、周倉、皇甫嵩、朱儁、韓當、鄒靖、荀彧、簡雍、盧植、義勇術士／謀士、張寶、于吉、華佗、張仲景、甘夫人、3 個教學角色與 UR 關羽／張飛。原有劉備、趙雲、黃巾弓兵／神射手與山賊鼓手另補基本衣裝或職業道具。

沿用現有 `HeroArt.Model` 優先載入 ProductionCharacters 的路徑，不修改遊戲規則或程式端顯示邏輯。夏侯惇不再回退至原本球體／方塊式的 ChibiModels。

## 原底材與新增製作

底材為專案已有 ProductionCharacters 蒙皮網格、骨架、衣裝及動畫。逐 ID 底材映射見 `roster-basic-coverage.json`，沒有將共用底材描述為全新獨立角色。

新增夏侯惇眼罩、短鬍與彎刀，呂布雙長翎與戟，公孫瓚白甲與持弓道具，軍官頭盔／標識、鬍鬚、羽扇、書卷、法杖、藥葫蘆、鼓與鼓槌。劉備新增雙劍及衣裝／臉／頭髮貼圖；趙雲補衣裝／臉貼圖、銀盔／龍紋／白纓、長槍和握持動畫素材。藍／紅／白衣甲貼圖由既有關羽衣甲 UV 底圖製作，趙雲與劉備貼圖使用各自既有 UV 底圖；生成提示見 `hero-stage17-prompts.json` 與 `roster-coverage-prompts.json`。UR 及教學模型是明確的共用底材變體。

- Unity 基本模型烘焙與 Windows 建置通過。
- 本輪 29 個新增／調整 ID 各截正面、斜面、背面、攻擊，共 116 張實機圖。最後修正華佗／于吉衣裝 UV 與呂布戟材質後，重新截取這 3 個 ID 的 12 張圖並替換證據。
- 捕捉紀錄沒有執行期例外；116 張均有模型且無畫面邊界裁切。`roster-basic-coverage/frame-bounds.json` 僅證明非空及裁切檢查，`visualApproval=false`。
- 已人工核對正面、背面、攻擊總覽：具備基本身體、臉、衣装、髮型與職業道具；實機圖見同名資料夾的 `contact-front.jpg`、`contact-back.jpg`、`contact-attack.jpg`。
- 正式資產 57 個 Prefab、29 個武將的路徑覆蓋檢查通過。本次接回的 Prefab／材質／動畫 GUID 引用無缺件。隔離工程的黃忠貼圖 GUID 已在新增材質中對回正式工程既有 GUID，未覆寫既有貼圖。
- 未重跑全部 57 個角色的全部動作；未調整的既有角色沿用前階段紀錄。

## 保留缺口，依要求停工

角色間仍共用臉、髮型、衣裝輪廓和基礎動畫；簡雍等角色仍有底材武器／職業道具混用。呂布戟刃、頭盔／長翎、鼓與部分杖件目前為基本幾何。新增髮型及帽盔接縫、手指接觸、披風／附件穿插、逐動作兵器握法與人物專屬比例尚未逐角精修。持弓部分待機／攻擊仍有位置和袖口遮擋缺口；鼓手仍沿用基礎動作，尚未製作專用擊鼓動畫。關羽新青龍刀握持、黃忠既有待修項與趙雲背面頭盔接縫仍待後續美術驗收。

目前完成的是「所有武將都有基本 3D 模型」，沒有宣告全部角色達到關羽人物認可水準或商用品質。此次 commit 後停止 3D 工作，不 push。
