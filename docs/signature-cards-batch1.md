## 0. 定價規則（沿用 GDD 02 §2）

- 預算 = 費用 + 0.5（卡位）＋稀有度加成（SR +1、UR +2）。
- 每 1 倍率的效價：單體 1.5；橫排／縱排 2.25；十字 3.0；全體 4.5。治療相同；護盾再 ×1.5；燃燒層數單體 1.5。
- 抽 1 張 0.5、回 1 費 1.0；全體物攻 +25%（2 回合）1.5；自身防禦 +50（2 回合）1.0；全場嘲諷 1 回合 1.5；破甲 25%（2 回合）單體 0.25、全體 0.75。
- 治療與護盾吃施放者的謀略，所以坦克不設計護盾牌。
- **坦克不負責輸出**（企劃 2026-10-09）：坦克牌只有防禦、嘲諷、抽牌。Boss 型坦克靠疊防禦扛 Boss；刷圖型／工具型坦克才有嘲諷。坦克防禦增益沿用 GDD 02 §6.1：自身 +50（2 回合）1.0、單體友軍 1.5、全隊 3.0。
- **戰士的爆擊強化 = 爆擊率增益**（企劃 2026-10-09；取代 GDD 02 §7 的待決）。暫定「自身爆擊率 +50%（2 回合）」值 1.0 費。
- **新機制**：表中標 🆕 的效果，核心目前還沒有，需要我實作（清單見 §4）。

## 5. 企劃回覆紀錄（2026-10-09）

1. 坦克不用管輸出：Boss 型坦克以提升防禦扛 Boss，嘲諷只給刷圖型／工具型坦克 → 已改燕人張飛、夏侯惇、張飛。
2. 擊敗後回費只在特定輸出牌（與公孫瓚被動）上，不會無限連鎖 → 不設上限。
3. 劉關張的被動不綁隊伍 → 劉備改為「仁君」（治療加成）。
4. 戰士的爆擊強化採「爆擊率增益」→ 呂布改為自身爆擊率 +50%。
5. Boss 型坦克給單體嘲諷 → 夏侯惇「剛烈」改為單體嘲諷＋自身防禦。
6. 第一批可以開始實作（數值實作後以模擬校準）。
