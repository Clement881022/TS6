# 人物展示構圖驗收

日期：2026-10-10

## 實際完成

原有 33 張 `ChibiSkin/full_*.png` 已具有透明背景，但圖片尺寸、人物占比與留白不同；僅統一 UI 外框會讓長武器人物顯得較小。

本階段保留原始 PNG，新增 `body-framing.json` 的逐人物身體中心、頭部與腳底定位資料。`HeroFigure` 按人物本體高度等比縮放，再把腳底對齊同一基準；頭飾、長武器與披風可超出本體基準，不拉伸圖片。主頁、主頁招募展示與武將／養成人物立繪共用此構圖。3D 模型顯示保留原流程。

這是既有素材的構圖與 UI 顯示接入，沒有重新繪製、去背或重新輸出統一尺寸的 PNG。

## 驗證

- 1600×900：裝備／主頁流程及全部 33 張人物分組構圖，共 19 張截圖，腳本通過。
- 1035×577：相同流程與人物構圖，共 19 張截圖，腳本通過。
- 1035×577：養成屬性、突破、人物與模型切換，共 8 個圖像產物，腳本通過。
- 手動檢視 6 張人物分組截圖的頭部／脚底基準線，以及主頁和養成頁的畫面，人物本體比例一致，主要武器與披風保留。
- 小視窗首次與另一個 Unity 測試同時執行時發生原生崩潰；單獨重跑後全部通過。尚未證明兩者有因果關係。

## 美術限制

部分原圖只有 362×362，放大後仍較柔。原圖的零星邊緣碎片（例如義勇謀士與鄒靖左側）未在本階段重繪；基準點依人物身體判讀，頭飾、姿勢與腳部陰影仍有視覺差異。本階段不代表原圖解析度或所有素材瑕疵已改善。
