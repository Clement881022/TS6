## 滑鼠拖曳修正

- 任務清單增加滑鼠左鍵拖曳：在任務卡非按鈕區域或清單空白處按住並上下移動，依位移捲動清單；只有內容超出可視區域時才捲動。
- 領取等按鈕不啟動拖曳，沿用原有點擊處理；滾輪與右侧捲軸保留既有處理。
- 指標擷取使拖曳離開清單時仍可接收放開事件；放開或失去擷取後停止拖曳，捲動位置限制在有效範圍。
