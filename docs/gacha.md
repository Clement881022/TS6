# 抽卡設計

> 狀態：草案（持續更新）。貨幣見 [progression.md](progression.md)，稀有度見 [heroes.md](heroes.md)。

## 1. 卡池結構

- **常駐池**：長期開放。
- **限定 UP 池**：限時，指定 UR 機率提升。

## 2. 機率

| 項目 | 設定 |
|---|---|
| UR 基礎機率 | 3% |
| UP 池出 UR 時 | 50% 為 UP 武將；**大小保底**：上一隻 UR 沒中 UP，下一隻 UR 必為 UP（2026-10-07 改，原為不保底） |
| 十連 | 保底至少 1 張 SR |
| 硬保底 | **80 抽必出 UR**（2026-10-07 採用，參數化可調；0 = 停用） |

SR / R 的機率分配待定。

## 3. 經濟錨點

- 免費玩家每月約可抽 100 抽。
- 以 3% 計，100 抽期望約 3 張 UR；UP 池約 1.5 張 UP 武將（無保底，個體差異大）。
- 這個錨點決定月卡、成長基金、禮包的定價與價值，見後續商業化文件。

## 3.1 前七天為特例

前 7 天為了留存，刻意前置新手紅利（約 100 抽，D1 約 30–50 抽），見 [days-1-7.md](days-1-7.md)。**第 8 天起回到上面的長期錨點**（每月約 100 抽）。新手紅利另計，月卡與成長基金按長期錨點定價。

## 4. 可控性要求

- 機率、保底、UP 比例全部資料驅動，可由後台調整。
- 大陸合規：機率須公示且與實際一致；調整需同步公示（見 README 合規章節）。

## 5. 待決

- 單抽價格（元寶）與十連折扣
- SR / R 機率與卡池內容、UP 池中 SR 是否也有 UP
- 常駐池 UR 數量與新手池 / 新手保底
- 重複 UR 轉換成突破素材的數量（見 progression.md）

## 6. 實作（2026-10-07，`src/SanGuo.Core/Meta/Gacha.cs`）

純規則、可由伺服器驗證，亂數用自研 `Rng`（相同種子結果一致）。機率單位為萬分比。

- **卡池資料**（`GachaPool`）：UR / SR 機率、各稀有度武將清單、UP 武將與 UP 比例、單抽 / 十連價格、十連保底 SR 開關、硬保底門檻（0 = 停用，目前停用）、新手池旗標（首次十連保底 UR）。
- **保底計數**（`PoolState`，每個卡池各一份，存在玩家存檔）：距上次 UR 的抽數、總抽數、十連次數。
- **規則**：
  - 單抽依基礎機率擲稀有度；UR 時若有 UP 則 50% 為 UP，未中不保底。
  - 十連最後一抽若前 9 抽全是 R，則提升為 SR。
  - 新手池的第一次十連若無 UR，最後一抽提升為 UR。
  - 硬保底啟用時，連續 N-1 抽未出 UR 則第 N 抽必出 UR。
- **公示**：`DisclosedRates()` 由同一份資料產生，確保公示機率與實際一致（合規）。保底另需在公告中說明。
- **結算**（`Gacha.Pull`）：檢查元寶、扣款、發武將；重複武將轉成 20 碎片（任何稀有度；一隻重複 = 一次突破的份量，見 progression.md 4.1）。
- **測試**：`GachaTests`（13 個）涵蓋機率統計、十連保底、新手保底、UP 比例與不保底、硬保底、同種子可重播、扣款與拒絕、重複轉碎片（改為每隻 20 碎片）。

SR / R 機率暫為 17% / 80%（建議值，待定）。

## 7. 設計指導原則（2026-10-07，依知乎〈聊聊抽卡这件事——从系统与用户行为数据全面分析抽卡设计〉）

> 以下把文章的主張對照到本作現況。「現況」欄是目前文件 / 程式已定的內容，「建議」欄是依文章提出、**待你決定**的調整；沒有你的確認不改程式預設值。

### 7.1 原則與對照

| 原則（文章） | 本作現況 | 建議 |
|---|---|---|
| **抽卡 + 升星拆分售賣**：整卡太貴，用升星 / 命座把一張卡分段賣，並在升星節點做質變，讓不同付費層級各取所需 | 突破 = 重複 1–5 隻，2★ / 5★ 為特殊效果（質變節點）✓ | 質變節點的強度是營運槓桿：要拉中 R 付費就強化 2★，要拉大 R 就強化 5★；設計新武將時有意識地控制 |
| **需要保底**：純隨機是幾何分佈，有人長期歪；1% 抽 500 次仍有 0.66% 一個沒中，大 R 流失得不償失 | UR 3%；硬保底參數已做但**預設停用** | 啟用保底（見 7.2 數字） |
| **常規保底 + 重置**（每 N 抽必出，出了重置）vs **概率遞增保底**（PRD / 軟保底，原神約 74 抽起遞增，多數人在期望前就出，有驚喜感） | 只有硬保底 | 軟保底手感更好；若做必須公示規則（合規） |
| **目標角色保底**（大小保底）：UP 池未中則下次必 UP；抽 UP 期望拉到約 1.5 倍保底成本 | UP 50%、**未中不保底**（2026-10-06 已定） | 見 7.2：不保底的 UP 期望是 2 倍，坑深；建議重新評估 |
| **積分商店（井）**：每抽累積積分，可兌換獎勵，填補保底之間的中期目標，並承接滿星後的溢出 | 無 | **缺口**：武將滿 5★ 後的重複碎片目前無用處；建議滿星重複 → 兌換幣，兌換商店可換碎片 / 強化素材 / 指定 SR |
| **經濟槓桿與溢出回收**：新手期抽卡有 1.5–4 倍價值槓桿，滿卡後性價比衰減 | 前 7 天約 100 抽新手紅利，之後回月 100 抽 ✓（槓桿前置）| 配合積分商店做溢出回收；月卡 / 基金定價時算入槓桿 |
| **圖鑑加成**（收集全局加成）：新手追不上老玩家的代價，適合滾服遊戲 | 無 | **不做**全局屬性圖鑑（本作不滾服）；收藏獎勵改給內容 / 外觀 / 語音（二遊做法）|
| **UP 池節奏**：限時、稀缺、配合宣發與信用卡還款日類的購買力節點；多 UP 拉高坑深適合大 R，付費率一般但 ARPPU 高 | 常駐池 + 限定 UP 池 ✓ | 初期單 UP；多 UP 與專屬池（武器池類）日後再說 |
| **卡池分檔**：新手池、階梯池（滿低階後追高階）、付費專屬池 | 新手池 ✓ | 付費專屬池不做（單一貨幣、輿論風險）；階梯池日後 |
| **概率作假**：保障體驗型可做（首抽必中、鉤子角色 N 次後保底、回歸必中）；付費型（倉檢：依付費意願降機率）**不做**，被驗證會有巨大社群風險 | 新手池首次十連保底 UR ✓ | 明確**禁止付費型作假**；保障型保底寫進公示（合規要求公示與實際一致，見 README 合規）|
| **刷初始**：新手池給高期望會催生刷小號產業鏈，污染留存資料，知情與不知情玩家體驗落差 | 新手池首次十連保底 UR（會被刷）| 提高刷的代價（帳號綁定、新手池只給 R/SR 加 1 UR 但不能指定），或接受並設計「可重置首抽」；之後依資料決定 |
| **進度條 / 目標可視**：保底進度顯示、碎片進度條，幫玩家衝長目標 | 無 | 抽卡介面顯示「距離保底還有 N 抽」；碎片合成進度條 |
| **每日免費單抽、十連打折、商城提醒** | 十連無折扣（已定）| 免費單抽可加（養成每日抽卡習慣、墊保底）；十連折扣不做（價格已定）；抽卡介面放禮包提醒 |
| **抽卡流程**：操作儀式感（滑動 / 拖曳）、品質預告演出（出金前的色光）、角色登場動畫、結果回顧頁、分享 | 無（尚未做客戶端抽卡畫面）| 客戶端抽卡畫面實作時採用：品質預告 → 登場 → 結果總覽（可略過）→ 分享圖；操作儀式感先做最簡單的點擊 / 滑動 |

### 7.2 保底數字（3% UR，單抽期望 33.3 抽）

| 方案 | 抽到 UR 的期望抽數 | 最壞情況 |
|---|---|---|
| 無保底（現況） | 33.3 | 100 抽沒出機率 4.8%、200 抽仍有 0.23% |
| 硬保底 90 | 31.2 | 90 抽內必出，6.6% 的人吃到硬保底 |
| 硬保底 80 | 30.4 | 80 抽，9.0% |
| 硬保底 60 | 28.0 | 60 抽，16.6% |
| 軟保底（50 抽起每抽 +3%，80 抽硬保底） | 27.4 | 多數人在期望前就出，幾乎沒人吃到硬保底 |

UP 池：不保底時抽到 UP 期望為 UR 的 **2 倍**（約 67 抽 ≈ 免費玩家 2 個月）；大小保底為 **1.5 倍**（約 50 抽）。免費玩家每月 100 抽 ≈ 1.5 個 UP（不保底）→ 2 個 UP（大小保底）。

**決議（2026-10-07，使用者同意）**：採用硬保底 80 + UP 池大小保底。程式預設值已改（`HardPityUr = 80`、`UpGuarantee = true`），保底規則文字由 `PityDescription()` 產生供公示。軟保底（遞增機率）暫不做，之後可再評估。
