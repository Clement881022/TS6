# 第零章：涿縣盜匪（10 關教學）

> 狀態：核心與客戶端已接線；世界觀見 [worldbuilding.md](worldbuilding.md)；機制、牌序與勝率驗證沿用 [demo-chapter1.md](demo-chapter1.md)（原「黃巾之亂」10 關，現已改為第零章的盜匪版本，黃巾留給第一章）。

## 1. 設計原則

- 第零章不浪費黃巾軍：敵人換成農民流寇 / 山賊 / 盜匪，**能力、數值、站位與牌序完全不變**（`DemoContent.Bandit*` 只換 id 與名稱），所以已驗證的「照教學打 100% / 忽略 0%」不變。
- 隨教學逐步發劉、張、關（首通關卡時獲得），並用劇情解釋他們為什麼加入。
- 戰鬥外的關卡 id 仍是 `1-1` ～ `1-10`（先不改存檔與伺服器）。

## 3. 發將節奏

- 劉備（第 1 關）：第一關就在隊伍裡負責治療；第 6 關再深化「上盾 / 治療」。
- 張飛（第 2 關）：嘲諷教學。
- 關羽（第 3 關）：破甲教學；之後劇情演桃園結義。
- 黃忠、龐統、趙雲：劇情定位為「路過的遊俠，暫時相助」，只在固定教學關上場，**不發給玩家**；之後章節才正式加入。
- 劉、關、張是 **SR**（正式套牌 1 張高級牌：張飛＝嘲諷、關羽＝旋風斬、劉備＝治療）。教學關為了帶出兩張技能卡，用 `ZhangFei(true)` 等「教學版」（套牌同 UR），所以第零章教學與勝率驗證不變；開放編隊後（第 9 關起）用的是 SR 正式版。坦克的高級牌順序改成「嘲諷、防禦姿態」，SR 張飛才拿得到突破表指定的嘲諷。
- 卡池目前沒有 SR 名單（SR 機率 0），劉關張只能由劇情取得，重複獲得轉碎片。
- 為補償我方變弱，資源副本「校場操練」的敵人強度由 (30,35) 調為 (22,26)。

## 4. 劇情播放

- 對白資料：`src/SanGuo.Core/Data/DemoStory.cs`（每關 `Before` 戰前、`After` 首通後）。
- 客戶端：`StoryPlayer`（`client/Assets/Scripts/App/StoryPlayer.cs`），沿用新手引導的視覺小說版面，逐句換說話者與立繪（有全身立繪用立繪，沒有用 3D 模型）。
- 戰前劇情只在該關尚未通關時播放，且每關只播一次（記在本機 PlayerPrefs）；首通結算後播 `After`，並顯示「獲得武將」。可略過。
