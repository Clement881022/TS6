# 商業化設計

> 狀態：草案。標示「建議值」的數字由 Claude 依業界常見做法暫擬，待你調整。
> 現階段原則：只定核心付費結構，細部營運活動（限購、通行證等）交給營運階段設計，不在此預先規劃。

## 1. 定位

- 付費結構以**月卡為主**，大額付費為輔。
- 大額付費以**競技場 / 定期排名模式**綁定（排名獎勵、賽季循環）。

## 2. 抽卡價格（已定）

| 項目 | 元寶 |
|---|---|
| 單抽 | 200 |
| 十連 | 2000（無折扣，十連保底 SR） |

免費玩家每月約 100 抽 = 約 20,000 元寶/月（見 [gacha.md](gacha.md)）。

## 3. 付費項目

### 3.1 元寶匯率（建議值）

1 人民幣 = 10 元寶，單抽約 ¥20。

### 3.2 月卡（價格待確認）

你提到「常見大小月卡約 300 多 / 600 多」，我不確定幣別與單位，以下以人民幣為暫定：

| 項目 | 小月卡（建議值） | 大月卡（建議值） |
|---|---|---|
| 價格 | ¥30 | ¥68 |
| 購買即得 | 300 元寶 | 680 元寶 |
| 每日領取（30 天） | 100 元寶 | 200 元寶 |
| 合計 | 3,300 元寶 ≈ 16.5 抽 | 6,680 元寶 ≈ 33 抽 |
| 每抽成本 | 約 ¥1.8 | 約 ¥2.0 |
| 附加權益 | 體力上限 / 回復加成 | 掃蕩次數、便利功能 |

### 3.3 成長基金（建議值）

- 售價 ¥98，總價值約 10,000 元寶（50 抽），每抽約 ¥2。
- 依主線進度 / 玩家等級分階段領取，鼓勵留存與推進。

### 3.4 首儲

- 要有首儲優惠（具體內容待營運階段設計）。

## 4. 競技場（大額綁定）

- 定期賽季排名，獎勵含元寶、專屬外觀 / 稱號、卡牌強化素材。
- 排名不應完全被付費壓過；強度差來自 UR 數量與突破，競技場本身以套牌構築與站位策略為主。
- 詳細規則待後續設計。Demo / 前 7 天先做簡易版（打 AI 防守隊、每日次數），之後演進或改名為終局內容。

## 5. 待決

- 月卡幣別與實際定價確認
- 付費玩家單月消費目標（ARPPU）與預期付費率
- 競技場規則、賽季長度、對戰是否為異步（對戰玩家的防守隊 AI）
- 外觀 / 皮膚是否作為第二條大額付費線
- 體力購買與元寶消耗的平衡
