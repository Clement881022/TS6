# UI 風格統一（2026-10-10）

以目前主城 Commercial／HomeLayout 與戰鬥 Commercial／BattleHud 為視覺基準。延用專案既有 ChibiSkin/gold.png、場景、立繪、圖示及 ChibiDisplay 字型，沒有宣稱本次重新製作這些底材。

新增 Unified.uss，在 PageHost 最後載入；其他頁面由 PageBase 掛上 unified-ui。主城與戰鬥主畫面不掛此類別，保留參考頁原版面。共用說明、訊息及劇情對話面板也統一為炭灰與金邊。

- 主面板：RGB 35/35/39，96% 不透明度，1 px 金邊 145/122/83，12 px 圓角。
- 標準文字：245/235/217；次要資訊：205/195/176；強調：241/208/139。
- 主操作：沿用主城金色材質，深棕文字、14 px 圓角。
- 選中分頁：72/62/47 底色與金色下緣；停用操作：39/39/43 與灰米色字。
- 保留稀有度、成功、警告、完成與鎖定狀態的辨識色。

涵蓋征戰、武將、養成、招募、素材副本、世界 Boss、任務、商店、編隊、帳號、登入，以及關卡詳情、招募機率、招募結果與說明彈窗。帳號表單原本寫死的褐色面板與輸入框改用共用樣式，移除登入美術佔位文字；沒有修改登入、購買、獎勵或戰鬥規則。

## 驗證方式

執行 tools/verify-unified-ui.ps1，使用 build/ui-layout-client-copy 隔離專案建置，不刷新原始專案的 Core DLL。-sanguoUnifiedShot 只在截圖驗收時啟用；採不持久化本機存檔，先招募建立非空武將資料，再巡覽全部頁面。

檢查頁首與面板實際解析色、主要版面邊界、截圖數量／解析度、執行期錯誤及新樣式診斷。戰鬥沿用 DebugValidateCommercialArt 驗證格子選取、頭頂 HUD、意圖排序及卡牌欄位。這些是結構與執行驗證，不代表遊戲規則測試或模型商用品質認證。

原 HomeLayout 的 last-child 會產生一則既有 USS 警告，驗證腳本單獨記錄為 baselineWarnings；其餘樣式錯誤仍判定失敗。未修改主城此既有規則。

截圖原圖與 manifest 位於 build/unified-ui-review；本資料夾保留縮圖總覽與驗收結果。帳號截圖採單機模式，登入表單可視驗收；未連線執行帳號綁定或真實交易。
