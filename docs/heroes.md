# 武將設計

> 狀態：草案（持續更新）。戰鬥規則見 [combat.md](combat.md)。

## 1. 陣營

- 魏、蜀、吳、群四陣營。
- 目前**不設陣營加成與羈絆**，陣營僅作為世界觀與分類標籤；未來可擴充。

## 2. 稀有度

| 稀有度 | 定位 |
|---|---|
| UR | 主力、抽卡核心 |
| SR | 兩種類型：①對策型（特定戰況極強、其他時候偏弱）②堪用型（強度略低、有上位替代） |
| R | 可上場的低階武將 / 新手期可用 |

N 僅作為升級素材，不是武將。武將分 R / SR / UR 三階。

## 3. 取得來源

- 抽卡：後期主力武將的主要來源。
- 碎片合成 / 活動 / 劇情解鎖：提供偏新手福利的前期主力，後期仍以抽卡武將為主。

## 4. 規模與表現

- 上線目標 20–40 名武將（單人開發範圍）。
- 3D Q 版模型；Demo 階段先用簡易佔位模型。

## 4.1 初始套牌規則

每名武將的初始套牌**固定 6 張，厚度一致**。稀有度只決定「高級牌」換掉幾張普通攻擊：

| 稀有度 | 普通攻擊 | 高級牌 |
|---|---|---|
| R | 6 | 0（只有一堆普通攻擊） |
| SR | 5 | 1（職業的第 1 張高級牌） |
| UR | 4 | 2（職業的兩張高級牌） |

普通攻擊的名稱統一叫「普通攻擊」（遠程職業打後排、近戰職業打同路最前排）。高級牌由職業決定，同職業的武將先共用同一組（程式：`DemoContent.BuildDeck` / `RoleSkills`），日後要做武將專屬技能，直接換掉對應那張即可。移動不在牌庫裡，是全隊共用的按鈕（見 combat.md）。

| 職業 | 第 1 張（SR 起） | 第 2 張（UR） |
|---|---|---|
| 坦克 | 防禦姿態：自己防禦 +100%・2 回合 | 嘲諷：挑釁 3 回合，自己防禦 +30% |
| 戰士 | 旋風斬（2 費）：同排傷害 100% | 豎劈斬（2 費）：同路縱列傷害 150% |
| 醫療 | 治療：血量比例最低的隊友 | 上盾：血量比例最低的隊友獲得護甲 |
| 軍師 | 攻擊鼓舞：全隊攻擊 +30%・2 回合 | 暴擊鼓舞：全隊爆擊率 +25%・2 回合 |
| 弓手 | 狙擊（2 費）：血量最低的敵人，傷害 200% | 破甲箭：任意敵人（玩家指定），傷害 60% + 破甲 50%・4 回合 |
| 法師 | 火計（2 費）：十字範圍傷害 + 火攻 | 火燒連營：引爆火攻並擴散 |

增益（防禦 / 攻擊 / 爆擊提升）同種重複施加時取較大的加成與較長的回合數，不疊加。昏亂、斷甲等進階機制不在初始套牌內，由突破 / 教學關借牌提供。

## 5. 每名武將的資料

- 定位（坦克 / 戰士 / 法師 / 弓手 / 醫療 / 軍師）
- 一組固定套牌（普攻、防禦 / 治療 / 移動等基礎牌 + 一兩張專屬主動牌）
- 被動
- 稀有度、陣營
