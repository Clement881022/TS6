# 武將設計

> 狀態：草案（持續更新）。戰鬥規則見 [combat.md](combat.md)。

## 1. 陣營

- 魏、蜀、吳、群四陣營。
- 目前**不設陣營加成與羈絆**，陣營僅作為世界觀與分類標籤；未來可擴充。

## 2. 稀有度

| 稀有度 | 定位 |
|---|---|
| UR | 主力、抽卡核心 |
| SR | 兩種類型：①對策型（特定戰況極強、其他時候偏弱）②堪用型（強度略低、有上位替代） |
| R | 可上場的低階武將 / 新手期可用 |

N 僅作為升級素材，不是武將。武將分 R / SR / UR 三階。

## 3. 取得來源

- 抽卡：後期主力武將的主要來源。
- 碎片合成 / 活動 / 劇情解鎖：提供偏新手福利的前期主力，後期仍以抽卡武將為主。

## 4. 規模與表現

- 上線目標 20–40 名武將（單人開發範圍）。
- 3D Q 版模型；Demo 階段先用簡易佔位模型。

## 4.1 套牌構成原則

每名武將的套牌 = **基礎牌為主** + **一兩張專屬技能**，被動另計。移動不在牌庫裡，是全隊共用的按鈕（見 combat.md）。

| 類別 | 說明 | 例 |
|---|---|---|
| 基礎牌 | 普攻、防禦、治療，每名武將有自己的名稱與倍率，可重複多張 | 張飛：攻擊 ×1、防禦 ×2；劉備：攻擊 / 防禦 / 治療各 ×1 |
| 專屬技能 | 武將的招牌，費用較高，常帶破釜（一次性）或狀態效果 | 燕人怒吼、溫酒斬將、桃園結義 |

定位由「基礎牌比例」區分：坦克偏防禦（加防禦 buff）、戰士前排攻防兼備、醫療偏治療與護甲、弓手打後排、軍師提供 buff 與抽牌費用。卡面以「基礎 / 技能 / 移動」標籤與底色區分。

## 5. 每名武將的資料

- 定位（坦克 / 戰士 / 法師 / 弓手 / 醫療 / 軍師）
- 一組固定套牌（普攻、防禦 / 治療 / 移動等基礎牌 + 一兩張專屬主動牌）
- 被動
- 稀有度、陣營
