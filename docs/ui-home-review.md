# 主城修正版交付紀錄

2026-10-09。依使用者要求，針對主城的視覺層次、拼貼感、導航重量、出征比例與資訊引導重新設計。

## 最終版面

- 84px 頂欄：玩家、置中品牌與資源各自成組。取消重複資源框及品牌副標，降低資訊噪音。
- 左側軍務／日常導航：全組共用一個細金邊漆面，只保留功能圖示、標題和用途說明；取消五個重複金框。
- 右下主線操作台：同時呈現章節、下一關、進度與狀態提示；全寬暖金出征按鈕為主要操作，編隊為次要操作。
- 取消滿版底欄及獨立武器／旗幟出征牌。兩組面板使用同一材質、邊框尺度與內距。
- 主城場景以內建 imagegen 修改配色，保留明亮 Q 版構圖；黃葉改為淡金、花樹改為柔粉、紅柱降低飽和感。原背景保存在 `art-chibi/home-before-refinement.png`，提示詞見 `art-chibi/home-refinement.json`。
- 次要文字使用 18px 設計字級，在 1280 寬視窗約為 12px，避免大螢幕看起來合理、小視窗卻難讀。

## 操作

出征會選取第一個尚未通關的關卡，進入地圖後自動開啟該關卡詳情。所有關卡皆通關時可重返最後一關。編隊按鈕維持實際解鎖條件，未開放時顯示開放關卡。

新增主城專用 `client/Assets/Resources/UI/Home.uss`，只作用於主城，最後載入；主線開啟意圖由 `GameSession` 傳給 `MapPage.OnReady`，在資料載入後消費。
